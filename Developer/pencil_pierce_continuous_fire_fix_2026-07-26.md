# 연필 관통 후 연속 발사 복구 — 2026-07-26

## 원인

`PencilThrow`가 활성 투사체가 하나라도 있으면 다음 쿨다운 발사를 즉시 반환했다. 관통 연필은 첫 적을 맞혀도 다음 적을 찾으며 최대 3.5초 살아 있으므로, 관통 업그레이드 후 정상 쿨다운 550ms가 지나도 새 연필이 생성되지 않았다.

## 수정

- 활성 투사체 전체 차단 조건을 제거했다.
- 발사 이벤트에서 활성 목록을 앞부분에 복사하고, 현재 타깃 스캔으로 만든 유효한 새 연필을 뒤에 추가한다.
- 새 배열은 발사 이벤트에서만 정확한 길이로 한 번 생성한다. 프레임 이동 경로에는 할당을 추가하지 않았다.

## RED → GREEN 검증 기준

- 기본 `pierce: 1` 연필은 단일 생존 적을 맞힌 뒤 사라진다.
- 실제 `useGameStore.applyUpgrade('pencilPierce')` 전이 뒤에는 `pierce: 2`가 된다.
- 첫 관통 타격 뒤에도 550ms가 지나면 기존 관통 연필 1개와 새 연필 1개, 총 2개가 렌더 목록에 남아야 한다.
- 사거리 3zm(2.25 units), 피해, 속도, 치명타, 3.5초 수명은 변경하지 않는다.
