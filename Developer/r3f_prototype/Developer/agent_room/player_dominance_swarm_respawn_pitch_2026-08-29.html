다수 리스폰 시스템

강해진 유저에게 더 강한 적을 억지로 붙이지 않는다. 대신 약한 몬스터를 더 많이 던져주어, 강해진 만큼 더 시원하게 쓸어버리는 핵앤슬래시 감각을 만든다.

버그 → 시스템

과다 리스폰 버그에서 오히려 핵앤슬래시 재미가 발견됨.

강화 X

체력/공격력 뻥튀기가 아니라 수량과 리듬으로 보정.

다수 O

강한 유저에게 약한 몬스터를 더 많이 제공해 쓸어버림 강화.

핵심 문제

현재는 스테이지별 스폰 스케줄을 따르고, 몬스터가 0마리가 되면 약 2초 안에 다음 스케줄을 당긴다. 하지만 유저가 충분히 강해지면 2초 보정만으로도 필드가 비고, 몬스터가 너무 빨리 정리되어 지루함이 생긴다.

핵심 해법

게임이 플레이어 우세를 판단하면 정규 스케줄 위에 약몹 보너스 웨이브를 얹는다.

판단 흐름

1최근 처치 속도 측정
2HP/피격 안정성 확인
3필드 압박도 확인
4우세 점수 계산
5약몹 다수 리스폰

해야 할 것

  • 약한 몬스터 수량 증가
  • 스폰 위치 분산
  • 쿨다운 적용
  • 정규 스케줄 유지

하지 말 것

  • 체력 뻥튀기
  • 공격력 과도 증가
  • 약한 유저에게 발동
  • 보스 패턴 중 억까 스폰

1차 발동 조건

  • 최근 처치 속도 높음
  • 필드가 자주 비어 있음
  • HP 55% 이상
  • 최근 피해량 낮음

1차 코드화 기준

const killRate10s = killsInLast10Sec / 10
const hpRatio = currentHp / maxHp
const emptyFieldRecently = recentEmptyFieldCount >= 2
const lowPressure = activeEnemyCount <= 3
const playerSafe = hpRatio >= 0.55 && recentDamage10s <= maxHp * 0.25

const dominanceScore =
  killRate10s * 1.0 +
  (emptyFieldRecently ? 1.0 : 0) +
  (lowPressure ? 0.7 : 0) +
  (playerSafe ? 0.8 : -1.0)

const shouldSpawnSwarm = dominanceScore >= 2.2

플레이어가 느껴야 할 감각

“내가 강해져서 몬스터가 더 많이 몰려오는데도 시원하게 잡힌다.”

주의

이 시스템은 난이도 자동 상승이 아니다. 강한 유저의 성장 체감을 살리는 쾌감 보정이다. 약한 유저에게 발동되면 즉시 밸런스 붕괴가 되므로 HP, 최근 피해량, 보스 패턴, 쿨다운 안전장치가 필수다.
