# 풀 좀비 피격 스파크 몸통 위치 수정

## 반드시 지킬 사항

- 풀링 적 피격 큐는 스파크 높이와 데미지 숫자 높이를 별도 스칼라 typed-array로 보관한다.
- 생성 경로는 각각 `0.42 * visualScale`, `0.95 * visualScale`을 전달한다.

## 앞으로 하면 안 되는 사항

- 단일 `hit.y`를 두 시각 효과에 재사용하지 않는다.
- 특수 적 피격 경로와 Firebase/Graphics Studio/localStorage는 수정하지 않는다.

## 검증

- RED는 단일 높이 큐에서 실패했고, Green은 집중 테스트 9개와 관련 전체 테스트 77개 통과로 확인했다.
