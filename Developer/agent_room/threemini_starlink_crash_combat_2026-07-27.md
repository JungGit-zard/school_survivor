# threemini 검토 기록 — 스타링크 추락 연출 연결

- 역할: Three.js/R3F 시각 연출 영향 확인.
- 결정: 기존 위성 낙하, 폭발, 좀론비스크 도주 모델과 SFX를 그대로 유지한다. 첫 착지 콜백만 전투 로직에 연결한다.
- 시각 좌표: 화면 내 보스가 있으면 기존 낙하 모델의 종점 x,z를 그 보스의 선택 좌표로 사용한다.
- 추적: 낙하 중 최신 보스 좌표를 써서 위성 종점, 폭발 효과, 도주 원점을 착지 피해 중심과 일치시킨다.
- 범위: 신규 모델·자산·Studio 값·Firebase·localStorage 변경 없음.
