# 신규 좀비 출현 스케줄 감사 + 재배치 (2026-11-04)

- 요청: Terry "새로 만들었다는게 어디 어떻게 언제 나오는지 스케줄 전부 확인해" / "특이 행동패턴 다시한번 다 확인하고 스테이지 진행 흐름에 맞추어서 다양하게 분포되어 출현하게 모두 분산해"
- 작성: Level_Mini (levelmini). 기준 트리 `F:/ezs-work/level` (origin 2be3fc2). 대상은 출시 스테이지 1~5뿐이다(6~10은 초안).
- 확인 방법
  1. 코드: 실제 스폰 표(`src/lib/burstEvents.js`), 스탯(`Enemy.jsx`), 행동(`novelZombieBehavior.js`), 비주얼(`projectileZombieVisuals.js`)을 대조했다.
  2. 런타임 프로브: `stageRuntimeProbe.js`를 헤드리스로 돌렸다(스테이지 1~5 × 시드 3개, 무적 카이팅 봇, 240초). 실제로 풀에 몇 초에 무엇이 나타났는지 프레임마다 셌다.
- 중요한 전제: **실제 게임은 `waveTimelines.js`의 웨이브 비중표로 스폰하지 않는다.** 런타임은 `burstEvents.js`의 고정 이벤트 표(+코인 몬스터, 빈 화면 보강, 지배 스웜, 4분 이후 연장 보강)만 발화한다. 그래서 아래 시각은 전부 이벤트 표 기준이다.
- 실제 등장 시각은 표보다 **약 5초(최대 11초) 빨라질 수 있다.** 화면이 비면 따라잡기(spawn catch-up)가 타임라인을 당긴다. 프로브에서 24초 이벤트가 19초에, 72초 이벤트가 67초에 나왔다.
- 탈출구는 210초에 열리고 마틸다도 210초(경고 205초)에 나온다. 210초 이후 이벤트는 바로 탈출하는 플레이어에게는 안 보일 수 있다.

## B. 재배치 (변경 후)

### B-1. 원칙

1. **난이도는 그대로, 종류만 바꾼다.** 변경은 전부 "같은 체력의 기존 좀비 자리를 신규 좀비로 맞바꾸기"다. 스테이지마다 마릿수와 체력 합이 정확히 같다. 시각을 옮긴 것은 1건뿐이다(스3 E40 1기를 3:36 → 2:48. 총량은 그대로이고 구간 사이로만 옮겨 간다).
2. **새 패턴은 혼자 먼저 보여준다.** 첫 등장 초에는 다른 신규 패턴의 첫 등장이 없다. 탱커·돌진·원거리 첫 등장과도 겹치지 않게 했다.
3. **쉬운 것부터, 섞는 건 나중에.** 스1은 E34 → E35 → E36을 하나씩 배우고 3:04에 둘을 섞는다. 스2·3·4는 오프닝에 앞 스테이지 패턴을 한 번 복습시키고 자기 신규를 하나씩 들인다. 스5는 앞 스테이지 패턴 8종을 쉬운 순서로 다시 보여준다.
4. **강한 패턴 3개 이상이 한 순간에 겹치지 않게 했다.** 강한 패턴 = 원거리 E04, 돌진 E05, 거대 E06, 포위·협공 대형, 크루, 보스, 마틸다. 신규 12종은 모두 예고가 있고 반대쪽이 항상 열리는 근접형이라 강한 패턴에 세지 않았다(체력 70인 E40·E42·E43은 "중간"으로 따로 봤다).
5. **건드리지 않은 것:** 스6~10, 투사체 좀비 15종(구현 전), 보스·마틸다·탈출 후 반복 웨이브(+10%/회, 상한 없음 그대로), 스3 반복 증원(사용자 지시 정본), 110초 전 스테이지 공용 보강, 포위·협공의 시각과 예고 배너, 스1 원거리 금지 규칙, 스3 조기 도입 사슬(E04@40·E05@72), 스4 조기 도입 사슬(E04@24·E05@40·E06@72), 미사일·무기·카드, 랭킹.
