# levelmini — 좀비 장애물 회피 설계 기록

작성일: 2026-07-25

## 게임플레이 결정

- 좀비는 장애물 안에서 생성되지 않는다. 일반 웨이브, E04, formation, 보스·호위, 마틸다, RZ 크루는 타입별 충돌 반경과 동일한 stage obstacle AABB를 검사한다.
- 고정 후보와 결정론적 근접·arena-wide 안전 후보도 실패하면 해당 적만 생성하지 않는다. 장애물 안 좌표를 강제로 반환하지 않는다.
- 이미 겹친 적은 리빌 전에도 최소 침투 축(MTV)으로 즉시 탈출한다. 경계 적용 뒤 유효한 네 방향 exit만 고르며, 이동은 전체 이동, 축 슬라이드, 접선 슬라이드 순으로 처리한다.
- 이동 의도가 있는데 0.5초 이상 의미 있게 움직이지 못한 적은 슬롯·세대 기반의 고정 배열 우회 상태를 사용한다. 1.2초에는 원점을 다시 고르지 않고 arena-wide bounded recovery를 시도한다.
- RZL/RZC는 obstacle 우회 뒤 원래 runDir로 복귀하며 map 밖 `+6`에서 despawn한다.

## 범위 제한

- 회전 소품의 보수적 world AABB는 그대로 유지했다. 스폰과 시뮬레이션은 같은 `collidesEnemyObstacle` 구현을 공유한다.
- 웨이브 수, 타이밍, formation 종류, 보스 호위 수는 변경하지 않았다. 안전 좌표가 없는 개별 spawn만 생략한다.
