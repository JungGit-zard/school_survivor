# 코인 몬스터(E08) 등장·동작 구현 정본 (2026-09-01)

## 1. 플레이어가 실제로 보는 등장 방식
- 모든 스테이지에서 스테이지 경과 90초와 180초에 코인 몬스터 1마리가 확정 등장한다.
- 확률 추첨이 아니라 고정 시각 이벤트이므로 한 판의 운 때문에 아예 못 보는 경우가 없다.
- 한 스테이지 최대 2마리다. 일반 웨이브와 초과시간 랜덤 적 풀에는 넣지 않아 희소성과 보상 가치를 유지한다.
- 등장 위치는 일반 버스트와 같은 `spawnPosForBurstType` 안전 위치 선택을 사용한다. 스테이지 경계 안, 장애물과 겹치지 않는 위치, 기존 적과 겹치지 않는 위치를 우선한다.
- pooled spawn drain을 통과하므로 한 프레임에 몰아 생성하지 않고 기존 모바일 성능 제한을 지킨다.
- 실제 몸은 바로 튀어나오지 않는다. 먼저 기존 큰 스폰 연기가 보이고 300ms 뒤 E08 몸체가 공개된다.
- 개발 모드에서는 HUD의 큰 노란색 `코인 몬스터` 버튼으로 즉시 1마리를 소환해 그래픽·피격·보상을 반복 검수할 수 있다. 이 버튼은 production 빌드에는 노출되지 않는다.

## 2. 전투 동작
- 타입 코드: `E08` / pooled numeric code `16`.
- 기본 스탯: HP 12, 이동속도 0.88, 접촉피해 6, XP 기준값 6, 시각 스케일 0.92, 접촉거리 0.26.
- 일반 pooled 추격 AI를 사용해 플레이어 쪽으로 이동하고, 접촉 쿨다운·피격·넉백·치명타·사망 처리는 다른 일반 좀비와 같은 검증된 경로를 탄다.
- 스테이지 상승 시 기존 `stageHpOverride` 규칙을 따라 체력이 증가한다. 보상 수량은 난이도와 무관하게 10개로 고정한다.
- 머리 동전, 양손 동전, 몸의 동전 가방이 있는 금색/갈색 전용 인스턴스 메시로 일반 좀비와 즉시 구별된다.

## 3. 처치 보상
- 사망 시 일반 교과서 확률 드롭을 타지 않는다.
- `ELITE_BONUS.E08 = { textbook: 0, gold: 10 }` 정본에 따라 골드 코인 10개를 확정 생성한다.
- 코인들은 기존 bounded runtime queue와 `GoldCoin` 수집 경로를 사용한다. 따라서 중복 사망 이벤트나 stale generation hit로 보상이 두 번 지급되지 않는다.
- 수집 시 기존 골드 저장/표시 로직을 그대로 사용한다. 별도 화폐를 만들지 않는다.

## 4. 스폰 스케줄 분리 이유
- E08 이벤트는 `COIN_MONSTER_RUNTIME_EVENTS`에만 둔다.
- `BURST_EVENTS` 등 정적 웨이브 HP 예산 표에는 넣지 않는다. 그래서 기존 스테이지 난이도 집계, 잡몹 마릿수 회귀 테스트, 보스 시각 파생값을 바꾸지 않는다.
- `getRuntimeBurstEventsForStage`가 각 스테이지 정적 표 뒤에 90초·180초 E08 이벤트를 합쳐 실제 런타임에만 전달한다.
- 확률 스폰, 처치 수 조건, 플레이어 우세도 조건은 사용하지 않는다. 조건이 여러 개 겹쳐 출현이 누락되는 문제를 피하기 위한 결정이다.

## 5. 예외와 안전장치
- 게임이 일시정지·게임오버·클리어 상태이면 기존 scheduler와 동일하게 큐를 소비하지 않는다. 재개되면 남은 스폰을 처리한다.
- 적 최대치가 찬 경우 기존 `clampZombieSpawnRequest`와 spawn drain 상한을 존중한다. 최대치를 뚫어 모바일 성능을 망가뜨리지 않는다.
- stage/game token 검증을 통과해야 spawn drain이 소비되므로 스테이지 전환 직전 예약된 E08이 다음 스테이지에 섞이지 않는다.
- E08은 보스가 아니며 일반 pooled enemy로 분류한다. 별도 React 적 객체를 늘리지 않는다.

## 7. 완료 판정
1. stage1~stage4 각각 runtime 표에서 E08이 정확히 90초·180초에 1개씩 존재한다.
2. 정적 웨이브 표에는 E08이 없어 기존 HP/마릿수 예산을 보존한다.
3. E08은 pooled type으로 스폰되고 300ms 연기 뒤 몸이 보인다.
4. 코인 전용 파트가 잘못된 STANDARD 파트를 참조하지 않는다.
5. 사망 1회당 교과서 0개, 골드 코인 정확히 10개다.
6. 개발 버튼 라벨은 축약 `C`가 아니라 `코인 몬스터`로 명확히 보인다.
7. 관련 Vitest, 전체 테스트, production build가 모두 통과해야 푸시한다.
