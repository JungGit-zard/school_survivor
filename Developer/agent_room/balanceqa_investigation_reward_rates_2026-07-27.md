# balanceqa 조사 보상 확률 검증 기준

작성일: 2026-07-27
역할: `balanceqa` 확률 경계·회귀 검토

## 승인 기준

| 대상 | 경계 및 기대 결과 |
|---|---|
| 학생 | `0.499`는 보상, `0.5`는 보상 없음 |
| 사물함 | 난수 호출 없이 항상 업그레이드 |
| 불레틴보드 등 기타 | `0.099`는 보상, `0.1`은 보상 없음 |

학생·기타 대상의 당첨 뒤 보상은 업그레이드 50%와 골드 10개 50%를 유지한다. 런타임은 조사 대상의 `subjectType`을 보상 정책에 전달해야 한다.

## 비대상 확인

Firebase, Graphics Studio, 브라우저 `localStorage`, 스테이지 배치·모델은 이번 검증 범위 밖이며 변경하지 않는다.
