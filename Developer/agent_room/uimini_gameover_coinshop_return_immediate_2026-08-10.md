# 게임오버 코인상점 복귀 팝업 즉시 표시

- Kanban: `escape-zombie-school / t_7937fda3`
- 담당: `uimini`
- 사용자 정본: 사망 후 코인상점을 나와 게임 화면으로 돌아오면 확정된 게임오버 팝업을 즉시 다시 표시한다.

## 원인과 가설

1. 코인상점 이동 시 `GameplayScreen`과 `HUD`가 해제되고 복귀 때 새로 만들어져 게임오버 지연 타이머가 재시작된다. **확인됨.**
2. 화면 이동 계층이 “이미 표시된 게임오버 결과”라는 상태를 HUD에 전달하지 않는다. **확인됨.**
3. HUD 내부의 `gameoverModalReady=false` 초기값이 새 마운트마다 기존 결과도 새 사망처럼 취급한다. **확인됨.**

## 변경

- 게임 화면에서 코인상점을 열 때 실제 게임 상태가 `gameover`인 경우에만 즉시 복원 표시를 기록한다.
- `ReadyGameApp → GameplayScreen → HUD`로 해당 표시를 전달한다.
- HUD는 복귀 첫 렌더부터 기존 결과를 표시한다.
- 이 표시는 한 번만 소비하며, 플레이 상태로 돌아간 뒤 발생하는 새 게임오버에는 기존 1초 전환을 유지한다.
- 새 타이머, 새 전역 상태, 점수·코인·보상 변경은 추가하지 않았다.

## 검증

- RED: 복귀 상태 전이 테스트에서 즉시 표시 값이 `true`가 아니라 `undefined/false`였고, HUD 첫 렌더에서 결과 오버레이가 없었다.
- GREEN: `ReadyGameApp.test.jsx`와 `HUD.test.jsx` 집중 실행, 38개 테스트 통과.
- `npm run build` 통과.
- 관련 없는 공유 작업공간 변경은 보존했다.
