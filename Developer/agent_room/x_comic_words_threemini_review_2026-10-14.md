# X 만화 장면 단어 현지화 검토

- 담당 프로필: `threemini` (그래픽/시각 콘텐츠 전문)
- 범위: X 이미지 전용, 한국어·영어·일본어·베트남어 각 5편의 4컷 단어 캡션
- 적용: 에피소드의 장소와 기물에 맞춘 짧은 캡션으로 교체. 식당 편 한국어는 `좀비! / 식당! / 우왕! / 악!`.
- 육안 확인: 한국어 식당 편과 일본어 체육관 편에서 캡션이 각 패널 안에 배치되고 기존 게임 시작 CTA가 보이는 것을 확인.
- 데이터 확인: 카탈로그 20개, 언어별 5개, 각 이미지 대사 4개, 게시 설정 pool 언어별 5개. 모든 경로 존재.
- 범위 확인: 새 컬렉션은 X에만 등록했고 Facebook 컬렉션/이미지는 수정하지 않음. 게시 작업은 수행하지 않음.
- 자동 게시 카드/배포: 수행하지 않음. 웹사이트 카드 생성 및 배포 점검은 오케스트레이터가 별도로 확인.
