# 스테이지 순차 해금·공통 타이밍 라우팅 기록 (2026-08-02)

## 요청 분류

- `levelmini`: 스테이지 해금 조건, 보스·탈출구·마틸다 런타임 타이밍과 직접 관련.
- `uimini`: 타이틀 치트 메뉴의 `모든 스테이지 해금` 버튼 노출·동작 확인과 관련.
- `balanceqa`: 네 스테이지 공통 규칙 및 기존 전투 회귀 검증과 관련.

구현은 메인 세션에서 진행하고, 완료 후 별도 적대적 검수 에이전트로 반복 검증했다.

## 적용 결과

- Stage 2~4는 각각 직전 스테이지의 탈출 클리어 기록이 있어야 열린다.
- 모든 탈출구는 210초, 모든 마틸다는 300초에 등장한다.
- 보스 등장 시각은 런 시작 시 170~190초 사이 정수 초로 한 번 결정되며, 실제 생성·HUD 경고·보스 압박 판정이 같은 값을 사용한다.
- 기존 타이틀 치트 메뉴의 `모든 스테이지 해금` 버튼을 유지하고 브라우저에서 Stage 1~4 입장 가능 상태를 확인했다.

## 검증

- 집중 테스트: 7개 파일, 190개 통과.
- 전체 테스트: 196개 파일·1,629개 테스트 전부 통과.
- 기존 HUD 음성 테스트의 오래된 기대 문자열을 현재 구현에 맞췄고, 전체 스위트 실행 시간에 따라 실패하던 성능 진단 테스트는 RAF 타임스탬프를 상대 시간으로 고정해 안정화했다.
- 프로덕션 빌드 및 후처리 게이트 통과.
- 실제 게임 화면에서 보스 경고·등장, 탈출구 활성화, 마틸다 등장 확인.

## 적대적 재검수

- `ce-adversarial-reviewer` 1차 검수에서 치트의 클리어 기록 오염, 마틸다 실체의 4.5초 지연, 생존 시간 기반 랭킹 자동 클리어, 관리자 보스 시각 불일치를 발견했다.
- 치트는 설정 플래그만 저장하도록 변경했고, 마틸다는 295초 소개 시작 후 300초 실체 생성, 랭킹은 명시적 탈출 클리어만 인정하도록 보정했다.
- 2차 검수에서 마틸다 5→1 카운트다운 소실과 관리자 랜덤 경계 오분류를 발견해 각각 시간 기준 유지와 `before/variable/after` 구간 표시로 보정했다.
- 최종 계정 경로 검수에서 치트 플래그의 hydration 후 복원 누락·계정 간 상태 누출과, 이전 계정의 늦은 hydration이 새 계정 진행도를 덮는 레이스를 발견했다. `progressStatus`와 UID를 기준으로 치트 상태를 다시 동기화하고, 현재 UID와 다른 원격 응답은 저장 런타임·인증 상태에 적용하지 않도록 보정했다.
- 사용자 직접 승인에 따라 타이틀 본문 카피도 `3분 30초 후 열리는 탈출구로 탈출하라`로 갱신하고 canonical 해시를 함께 갱신했다. 로비 스테이지 설명도 같은 3분 30초 탈출 목표를 사용한다.
- 최종 적대 검수 결과 P1/P2 발견사항 0건.
- 최종 회귀: 196개 파일·1,629개 테스트 통과, 프로덕션 빌드와 title/BGM/B02 보호 게이트 통과. 실제 브라우저에서도 새 타이틀 문구와 기존 4분 문구 제거를 확인했다.
