# levelmini 조사 보상 확률 검토 기록

작성일: 2026-07-27
역할: `levelmini` 게임플레이·성장 보상 검토

## 판단

- `locker`는 항상 `{ type: 'upgrade' }`를 반환해 무기 업그레이드 선택 기회 1회를 보장한다.
- `student`는 총 보상 확률 50%이며, 당첨 뒤 업그레이드와 골드 10개를 각각 50%로 유지한다.
- `bulletinBoard`를 포함한 기타 대상은 기존 총 보상 확률 10%와 기존 50:50 보상 풀을 유지한다.
- 현재 조사 가능한 사물함은 스테이지 2 배치에만 있고, 스테이지 1에는 학생 조사 대상만 남긴다. 배치·모델 변경은 없다.

## 범위 확인

- `{ type: 'upgrade' }`는 기존 업그레이드 선택 기회 의미를 재사용한다. HUD·store 모드 추가는 하지 않는다.
- Firebase, Graphics Studio, 브라우저 `localStorage`는 변경하거나 사용하지 않는다.
