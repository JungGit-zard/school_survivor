# levelmini 검토 기록 — 스타링크 추락 전투

- 역할: 게임플레이 규칙 확인.
- 결정: 유효 발사 15주기마다 추락한다. 화면 내 생존 보스가 있으면 보스를 우선하며, 없을 때만 플레이어 주변 무작위 지점을 쓴다.
- 피해: 착지 순간의 지우개 폭탄 현재 runtime damage/radius를 1회 사용한다.
- 추적: 선택 보스는 낙하 중 최신 좌표로 갱신하며, 사망·제거되면 마지막 유효 좌표를 유지한다.
- 범위: 모델, 자산, Firebase, Graphics Studio, localStorage 변경 없음.
