## 2. 공통 제작 방식 (두 보스 모두)

1. 몸: Kenney Mini 6조각 강체 몸(다리2·몸통·팔2·머리). 이미 게임 GLB 안에 있는 몸이면 GLB 몸 바이트 0 추가.
2. 보스 비율: 머리는 그대로, 몸통 ×1.3, 팔 ×1.2, 다리 ×1.35를 굽기 때 한 번 적용(Mini 몸은 머리가 커서 그대로 키우면 아기처럼 보인다). 관절이 원래 떨어진 조각이라 이음새 문제는 그림에서 보이지 않았다.
3. 색: 기존 Mini 좀비와 같은 방식 — 색판 칸 옮기기(UV 재지정). 보스용 새 색 칸 22개를 색판 끝에 추가(현재 52칸 → 74칸, 한도 88칸). 머리카락 칸을 높이로 나눠 정수리만 피부색으로 바꾸는 식의 "삼각형 단위 색 나누기"도 굽기 때 가능함을 확인(B05 안 A의 대머리+흰 옆머리).
4. 소품: 도장·출석부·종·마이크·안경·명찰·메달·띠는 굽기 스크립트가 만드는 블록 소품(복사기 머리와 같은 방식)으로 손·몸통 조각에 합친다 → 그리기 호출 추가 0.
5. 툰 셰이딩 + 반전 외곽선: 기존 Mini 레이어와 같은 재질·같은 외곽선 두께 비율.
6. 보스는 지금도 무리 그리기(instancing)가 아니라 한 마리씩 그린다(`Enemy.jsx INSTANCED_TYPES`에 없음). 그래서 새 보스는 `MiniZombieLayer`에 넣지 않고, GLB 조각을 읽어 쓰는 보스 전용 메시 컴포넌트 하나(가칭 `MiniBossMesh`)로 그린다. 포즈는 지금처럼 절차 포즈(포즈 표 + 프레임마다 보간)로 한다.
7. 크기: 게임 수치(`ENEMY_STATS.scale`, 접촉 거리, 충돌)는 바꾸지 않는다. 그림 크기만 보스 메시 안의 고정 배율로 현재 키(1.86 / 1.82)에 맞춘다.
