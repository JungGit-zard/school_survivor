# 무기 도감 UI 구현 기록

- 날짜: 2026-08-22
- Kanban: `t_6e374e99` (`uimini`)
- 범위: 로비 무기 도감, 코인 상점 잠금 항목 상세 이동, 결과창 도감 진입 UI

## 구현

- `WeaponModal`에 전체·해금·잠김·이번 해금 필터와 선택 무기 상세를 추가했다.
- 누적 조건은 `현재/목표`와 진행 막대로 표시하고, 한 판 조건은 목표만 표시한다.
- 하나코·바이키티 커터칼·선긋기는 계정 해금/잠김으로 취급하지 않고 `런 중 조합`으로 분리했다. 계정 해금 수는 17종 기준이다.
- 로비 기존 `무기` 버튼에 새 해금 배지를 연결했다.
- 결과창의 새 무기 안내에서 선택 무기 상세를 연 도감으로 이동할 수 있게 했다.
- 코인 상점의 잠긴 영구 강화 항목은 구매 대신 해당 무기 도감 상세를 연다.
- Firebase·Zustand 해금 판정·저장 구조는 수정하지 않았다. 4선택지 레벨업, 퀘스트 가방, 보스 패시브도 변경하지 않았다.

## 후속 보정

- 도감이 닫힐 때 기존 `acknowledgeNewWeaponUnlocks` 액션만 호출해 NEW 배지를 제거한다. 열린 도감에는 전달받은 신규 목록을 그대로 표시하며, 별도 영구 discovery 저장은 추가하지 않았다.
- 조합 무기 3종은 계정 무기 17종의 해금 수/잠금 필터에서 제외하고 런 중 조합 발견 조건으로 표시한다.
