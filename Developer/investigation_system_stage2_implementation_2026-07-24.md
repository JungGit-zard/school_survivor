# 스테이지 2 조사 시스템 구현 기록

작성일: 2026-07-24

## 구현 내용

- 기존 쓰러진 학생 근접 조사를 공용 조사 대상 판정으로 확장했다.
- 스테이지 2의 `corridorLockerBank`를 ‘사물함’으로 조사 가능하게 했다.
- 스테이지 2의 `corridorLostFoundBoard`를 게임 UI에서 ‘불레틴보드’로 조사 가능하게 했다.
- 학생은 기존 0.5 월드 유닛 반경을 유지했다.
- 벽면 물체는 충돌체 바로 앞에서도 발동하도록 1.65 월드 유닛 반경을 사용한다.
- 대상별 조사 완료 상태는 런 메모리에서만 관리하며 새 게임 키에서 초기화한다.
- 기존 10% 조사 보상 추첨 함수를 모든 조사 대상이 공통 사용한다.
- 조사창에 학생·사물함·불레틴보드의 이름과 문구가 구분되어 표시된다.

## 저장 원칙

조사 대상의 런당 1회 상태는 현재 플레이에만 필요한 임시 상태이므로 메모리에서만 유지한다. 골드 등 기존 계정 진행 보상은 프로젝트의 기존 Firebase 저장 요청 흐름을 사용하며 `localStorage`를 추가하지 않았다.
