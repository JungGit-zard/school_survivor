광택 살펴보기

영상과 동일한 38개 평면으로 돌의 형상을 재구성하고 광택 수식을 GPU 셰이더로 옮겼습니다. 실시간 조명·블룸은 영상과 픽셀 단위로 같지 않습니다.

씰온라인 원본 복원 아님. 게임·Studio·Firebase에 연결하지 않습니다. 조절값은 페이지를 닫으면 사라집니다.

어떤 도구로 만들었나요?

원본 시안: Python + NumPy(형상·광택), Pillow(이미지·블룸), OpenCV(MP4).
현재 뷰어: Three.js + GLSL + OrbitControls.
3ds Max/Blender/AI 이미지 생성은 사용하지 않았습니다. 무늬는 별도 텍스처 이미지가 아니라 수학 함수로 계산합니다.
