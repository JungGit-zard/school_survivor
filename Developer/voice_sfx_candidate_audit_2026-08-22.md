# Escape Zombie School 음성 효과음 후보 리스트업

작성일: 2026-08-22
목적: Node 절차 합성으로 제작할 "입/목/숨/울음/비명/웃음/포효" 계열 음성형 SFX 후보를 정리한다.

## 기준

- 사람이든 좀비든 동물이든, 생물이 입/목/숨으로 낼 수 있는 소리면 음성 후보.
- 무기, 코인, 상자, 포탈, 발소리, 일반 UI 클릭음은 기본적으로 음성 후보에서 제외.
- 반복 빈도가 높은 소리는 짧게 만들고 쿨다운/보이스 캡을 유지한다.
- 정확한 대사 녹음이 아니라, 8비트/레트로 source-filter 절차 합성으로 "말과 괴성 사이"의 발성을 만든다.

## 1순위: 반드시 필요한 음성형 SFX

### 좀비/몬스터

- `zombieDeathGrunt`
  - 지점: 일반 좀비 사망
  - 의도: 짧은 "으윽/억"
  - 상태: 기존 구현 있음, 절차 합성 유지

- `zombieDeathHeavy`
  - 지점: 덩치/차저 좀비 사망
  - 의도: 낮은 "우어억"
  - 상태: 기존 구현 있음, 절차 합성 유지

- `zombieDeathShriek`
  - 지점: 러너/빠른 좀비 사망
  - 의도: 높은 "끼야악"
  - 상태: 기존 구현 있음, 절차 합성 유지

- `zombieDeathGurgle`

- `zombieDeathBellow`
  - 지점: 거대 좀비 사망
  - 의도: 낮고 긴 "끄아아앙"

- `zombieRunnerScreech`

- `zombieChargeRoar`

## 2순위: 만들면 확 좋아지는 음성형 SFX

- `zombieSpawn`
  - 지점: 일반 좀비 등장
  - 의도: 짧은 "으어/그으"
  - 상태: 음성형으로 재합성 대상

- `zombieGroan`

  - 의도: 낮게 깔리는 "으으"
  - 상태: 음성형으로 재합성 대상

  - 지점: 큰 좀비 그로울
  - 의도: 낮고 무거운 "그어어"

- `playerHeal`
  - 지점: 실제 HP 회복 발생
  - 의도: "후우/하아" 안도 숨
  - 상태: 신규 ID 추가 및 `healPlayer()` 경로 연결

- `dogeEscape`
  - 지점: 도지 도망
  - 의도: 짧은 "멍/왈" + 도망 느낌
  - 상태: 음성형으로 재합성 대상

- `dogeYelp`
  - 지점: 도지 충돌/낑
  - 의도: "깨갱/끼잉"
  - 상태: 음성형으로 재합성 대상

- `dogeDeath`
  - 지점: 도지 처치/사라짐
  - 의도: 너무 잔인하지 않은 짧은 낑/팡
  - 상태: 음성형으로 재합성 대상

- `inuconBite`
  - 지점: 이누콘이 붙은 좀비를 물거나 밀어낼 때
  - 의도: "왕/컹"
  - 상태: 신규 ID 추가, 이누콘 히트/밀치기 경로 연결 후보

- `inuconHeal`
  - 지점: 이누콘 회복 발생
  - 의도: 따뜻한 낑/숨 + 회복감
  - 상태: 신규 ID 추가, 이누콘 회복 경로 연결 후보

- `rzlWhistle`
  - 지점: 런좀비 리더/크루 포메이션 등장
  - 의도: 리더가 부르는 휘파람
  - 상태: 유사 음성/호출음으로 재합성 대상

- `stage2GuardWhistle`
  - 지점: 스테이지2 경비 좀비 호출
  - 의도: 경비 호루라기/휘파람
  - 상태: 유사 음성/호출음으로 재합성 대상

- `matildaCountdownEnd`
  - 지점: 마틸다 카운트다운 종료
  - 의도: 숨 멎는 듯한 끝 신호 또는 짧은 웃음
  - 상태: 음성형으로 재합성 대상

## 3순위: 취향 보고 나중에 결정

- `playerLowHpBreath`
  - 지점: 주인공 체력 낮음
  - 의도: 거친 숨
  - 판단: 반복 피로도가 높아 이번 1차 구현에서는 보류

- `playerLevelUpVoice`
  - 지점: 레벨업
  - 의도: "좋아/해냈다" 혹은 밝은 기합
  - 판단: 게임 분위기 취향을 타므로 이번 1차 구현에서는 보류

- `playerEscape`
  - 지점: 스테이지 탈출 성공
  - 의도: "살았다/후우"
  - 판단: 클리어 징글과 충돌 가능. 이번 1차 구현에서는 보류

- `chibikoVoice`
  - 지점: 치비코 공격/히트
  - 의도: "얍/에잇"
  - 판단: 공격 반복 빈도 높음. 이번 1차 구현에서는 보류

## 구현 메모

- 생성 방식: Node.js 스크립트가 CPU로 파형을 계산해 `.wav`를 만들고 ffmpeg로 `.ogg`/`.mp3` 또는 필요한 포맷으로 변환한다.
- 하드웨어 사운드카드를 이용해 만드는 것이 아니라, 코드가 피치/포먼트/노이즈/엔벨로프/비브라토/왜곡을 계산해 음성처럼 들리는 파형을 만든다.
- 게임 런타임은 `SOUND_MAP`에 등록된 ID를 `emitSfx`/`playSfx`로 재생한다.
