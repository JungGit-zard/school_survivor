# B04 급식 국자 시각 구현 기록

## 적용 범위

- Stage 4 B04의 `급식 국자` 바닥 원 세 개만 표시한다.
- 1.2초 예고에는 주황·노랑 표면과 짙은 외곽선의 원형 표식을 보인다.
- 폭발은 세 원이 동시에 밝아지는 상태로 250ms 유지한다.
- 폭발 250ms 동안에만 단발 피해 판정도 유지되어, 표시와 피해가 같은 시간 구간을 사용한다.

## 보존한 범위

- 원 밖 급식실 바닥은 원래색 그대로다.
- 전체 화면 흔들림·급확대, 투사체, 콜라이더, 소환, 새 자산을 추가하지 않았다.
- B02, B03, BIG_SPAWN_SMOKE, 모델, Graphics Studio, 타이틀, HUD, Firebase, 5173은 수정하지 않았다.

## 확인

- B04 상태 시간과 B04 시각 상태 계약을 focused 테스트에 추가했다.
