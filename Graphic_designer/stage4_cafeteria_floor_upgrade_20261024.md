## 4. 텍스처 계약과 실현 경계
- 정확한 타일 0.8 units, 아레나 18.72×32 units, UV 반복 23.4×40을 보존한다.
- 단일 반복 이미지에는 타일 한 칸을 담는다. 여러 칸을 넣으면 실효 줄눈 밀도가 달라진다. 좌우·상하 이음과 모서리 밝기를 맞추고, 23.4 반복의 가장자리 부분 타일을 억지로 정수화하지 않는다.
- 미세 점·가는 줄의 mipmap 소실·모아레는 실제 카메라에서 확인한다. 명암·입자 밀도를 먼저 줄이고 반복 얼룩·seam을 점검한다. 픽셀 해상도는 후속 비교로 결정한다.
- TexturedFloor는 MeshLambertMaterial의 map + baked lightMap. 기존 roughness 조절값은 없다. 무광은 이미지에 그린 인상이지 재질 수치가 아니다. 조명·lightMap 변환 불변.
- 권장 1차는 텍스처만 교체하는 후속 후보. 전역 반복 타일에 북/남 색면을 굽으면 맵 전체에 재등장한다. 구역화는 선택적 2차로 분리하고 담당자가 기존 배치·UV 경로를 확인한 뒤 별도 승인한다. 추측 좌표를 정본으로 채택하지 않는다.
