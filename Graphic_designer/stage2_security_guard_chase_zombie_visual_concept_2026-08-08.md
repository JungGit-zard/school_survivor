# Stage 2 경비원 추격 좀비 비주얼 컨셉

## 공통 방향

- 기존 `ZombieMesh.jsx`의 복셀/툰 스타일, 블록 비율, 외곽선 규칙을 그대로 따른다.
- 멀리서도 `도망가는 한 명`과 `제복을 입은 추격대`가 즉시 구분되어야 한다.
- 두 모델은 완전히 옷을 입은 코믹 캐릭터다. 노출이나 성적 묘사는 사용하지 않는다.

## RZT — 도망가는 바바리맨 좀비

- 실루엣: 무릎 가까이 내려오는 황갈색 트렌치코트, 뒤로 날리는 코트 자락, 앞으로 뻗은 목과 다급한 전력질주 자세.
- 색상: 코트 황갈색, 안쪽 셔츠 연회색, 넥타이 주황/적색, 바지 짙은 갈색, 피부는 기존 좀비 녹색 계열.
- 얼굴: 크게 뜬 눈, 비대칭 눈썹, 벌어진 입으로 당황한 표정을 만든다.
- 소품: 한 손에 구겨진 신문을 들고 달린다. 코트는 항상 닫힌 상태다.
- 가독성: 앞에서는 밝은 넥타이, 옆에서는 긴 코트 자락, 뒤에서는 넓은 코트 등판으로 식별한다.

## RZG — 추격하는 경비원 좀비

- 실루엣: 남색 경비모, 각진 남색 제복 상의, 형광 노란 완장, 검은 바지와 단단한 신발.
- 색상: 남색 몸통과 모자, 황금색 배지, 형광 노란 완장, 피부는 기존 좀비 녹색 계열.
- 얼굴: 찡그린 눈썹과 굳게 다문 입으로 추격 의도를 표시한다.
- 소품: 한 손에는 짧은 검은 경비봉, 가슴에는 금색 배지를 둔다.
- 가독성: 앞에서는 배지, 옆에서는 경비봉, 뒤에서는 형광 완장과 모자 띠로 식별한다.

## 질주 애니메이션

- 스테이지 3 러닝 좀비의 빠른 팔 펌핑, 큰 다리 보폭, 전방으로 숙인 몸통 애니메이션을 공유한다.
- `RZT`는 팔을 더 벌리고 코트 자락이 반대 위상으로 흔들려 도망치는 느낌을 낸다.
- `RZG`는 경비봉 든 팔의 진폭을 조금 줄이고 다른 팔을 크게 흔들어 추격 자세를 낸다.
- 별도 애니메이션 시스템이나 별도 변형 계산은 만들지 않는다.

## Graphics Studio 연결 강제 조건

- `RZT`, `RZG`는 `graphicsStudioConfig.js`의 공용 좀비 카탈로그에 등록한다.
- 런타임 모델은 반드시 `StudioTunedGroup itemId={getStudioZombieItemId(type)}`로 감싼다.
- 모델 파트는 기존 `ZBlock` 자식 순서와 숫자 child path 방식으로 선택한다.
- `ZOMBIE_E01_STUDIO_TRANSFORM_CONNECTION_CODE.md`에 적힌 공용 변형 체인 이외의 독자 함수, 독자 ID, 로컬 상태, fallback은 금지한다.
- Studio Apply 결과와 실제 스테이지 2 렌더링은 같은 `ZombieMesh` 런타임 소스를 사용한다.
