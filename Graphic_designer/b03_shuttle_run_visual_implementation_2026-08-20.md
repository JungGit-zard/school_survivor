# B03 왕복 오래달리기 시각 구현 기록

## 적용 범위

- Stage 3 B03의 `왕복 오래달리기` 바닥 레인만 수정했다.
- 예고 1.25초에는 노란 표면과 진한 갈색 외곽선의 단일 가로 레인을 표시한다.
- 발동 중에는 첫 번째 통과와 복귀 통과를 서로 다른 주황·적색 표면으로 구분한다.
- 경직 중에는 같은 레인을 낮은 불투명도로 남겨 위험 종료를 알린다.

## 보존한 범위

- 레인 밖 체육관 바닥 색은 변경하지 않았다.
- B02, B04, 모델, Graphics Studio, 타이틀, HUD, Firebase, 5173은 수정하지 않았다.
- 화면 흔들림이나 급확대는 추가하지 않았다.
