# 로자리의 방

- 요청: 타이틀에 `로자리의 방` 버튼, 소녀다운 침실, 승인된 로자리 모델의 이동, 앞으로 옷을 갈아입을 옷장.
- 분홍·크림·라벤더 침실에 침대, 옷장, 화장대, 하트 러그, 인형, 책, 꽃병, 커튼과 액자 배치.
- 승인 GLB를 그대로 사용하고, 실제 파츠 관절로 절차적 보행. 화면 기준 외곽선 6 CSS 픽셀 유지.
- 방향키/WASD 및 화면 방향 버튼으로 이동. 옷장 근처 버튼 또는 옷장 클릭으로 패널 열기. ESC는 옷장 닫기, 다음 ESC는 타이틀 복귀.
- 현재 교복 표시. 추가 의상 및 실제 복장 교체는 아직 구현하지 않음. 의상 자산/선택이 정해지면 이어서 작업.
- 기존 게임/타이틀 캐릭터, 인증, Firebase 데이터는 변경하지 않음. 로컬 개발 화면에 적용, 배포하지 않음.
