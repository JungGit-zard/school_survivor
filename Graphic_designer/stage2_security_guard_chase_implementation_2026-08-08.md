# Stage 2 경비원 추격 좀비떼 그래픽 구현 기록

## 화면에서 읽히는 두 역할

- `RZT`: 황갈색 긴 트렌치코트, 금색 스카프, 어두운 바지와 신발, 놀란 눈과 입으로 도망가는 바바리맨 좀비를 표현한다. 전체 착의 모델이다.
- `RZG`: 남색 경비 모자와 제복, 전면 노란 안전조끼, 금색 배지, 어두운 하의로 뒤쫓는 경비원 좀비를 표현한다.

## 일관성

- 두 모델은 기존 복셀 `ZBlock`과 검은 외곽선 규칙을 유지한다.
- 기존 달리기 팔·다리·상체 애니메이션을 공유한다.
- Graphics Studio에서는 `zombie-rzt`, `zombie-rzg` 카탈로그 항목으로 선택되며, 게임 풀 렌더와 같은 Firebase Studio 변형 체인을 사용한다.
