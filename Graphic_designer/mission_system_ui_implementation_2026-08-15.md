# 미션 시스템 UI 구현 기록

작성일: 2026-08-15
담당: UI_Mini (Terra fallback)

## 적용 범위

- 로비 하단 네비게이션의 기존 무기·랭킹·상점 순서를 유지하고, 오른쪽 네 번째 48px 버튼으로 `미션`을 추가했다.
- `MissionCenter` 화면을 추가했다. 추천·진행·완료·전체 필터를 제공하며 전체 탭에서 30개 카탈로그 미션을 모두 표시한다. rollout, future, hidden 조건은 사용하지 않는다.
- 카드에는 한국어 제목·목표·숫자 진행·완료/받음 상태를 표시한다. 사용자 승인으로 `MISSION_REWARD_APPROVED=true`이며, 완료·미수령 미션에만 48px 이상 `받기` 버튼을 활성화한다. 보상은 `보상 N골드`로 표시하고, Firebase 원자 claim 성공 후에는 `받음` 상태로만 표시한다.
- 미션 고정은 최대 2개이며 `togglePinnedMission` 뒤 `saveMissionProgress`를 호출한다. Firebase 저장 실패/로그인 없음은 안내만 하고 플레이를 막지 않는다.
- HUD 좌측 상단 컨트롤 아래에 접이식 최대 2개 고정 미션 추적기를 추가했다. 보스·투사체·마틸다·대형 경고와 대화/일시정지/결과 화면에서는 숨긴다.
- 게임오버/클리어 결과에는 최대 1개 대표 진행과 완료 수를 1~2줄로 표시하고, 기존 기본 CTA의 순서·크기를 바꾸지 않은 별도 `미션 센터` 이동 버튼을 추가했다.

## 변경하지 않은 범위

- 타이틀, Graphics Studio, 오디오, 인증, 스탯, 스폰, 타이밍, stageConfig, 기존 Firebase 원자 보상 수령/claim 로직을 변경하지 않았다.
- localStorage 또는 다른 로컬 저장소를 사용하지 않았다.

## 검증

- 사용자 지시에 따라 테스트, 빌드, 브라우저 실행은 하지 않았다.
- 완료 후 변경 diff를 1회 확인한다.
