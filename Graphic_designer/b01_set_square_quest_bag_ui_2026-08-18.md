# B01 삼각자 보스 패시브 — 퀘스트 가방 UI

## 표시 위치

퀘스트 가방 패널의 맨 아래에 `보스 패시브 아이템` 구역을 둔다. 기존 퀘스트 목록과 보유 퀘스트 아이템은 그대로 유지한다.

## 슬롯 구성

- 총 8칸을 4열 × 2행 격자로 표시한다.
- 모바일 폭에서도 각 칸이 줄어들지 않도록 패널 폭 안에서 동일 크기로 배치하고, 패널 자체의 기존 세로 스크롤을 사용한다.
- 아직 획득하지 않은 칸은 점선 테두리와 `+` 표식의 빈 슬롯으로 보인다.
- B01 처치 후 첫 슬롯은 금색 테두리와 `📐` 아이콘으로 표시한다.

## 첫 보스 패시브

- 이름: 삼각자
- 효과 문구: 커터칼·30cm 자·바이키티 공격력 +5%
- 접근성 이름: `삼각자 — 커터칼·30cm 자·바이키티 공격력 +5%`

다음 보스 패시브 아이템은 빈 7칸에 순서대로 추가한다.
