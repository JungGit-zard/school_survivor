# Stage 1 반장 붉은 교복

- 대상: `stage1-student-south-01` (`stage1-attendance` 퀘스트의 실제 반장)
- 변경: 교복 상의와 양쪽 소매를 기존 프로젝트 붉은색 `#c23535`로 지정
- 구분: `stage1-student-west-01`은 말빨기술책 퀘스트 제공자이며 반장이 아니므로 기본 파란 교복 유지
- Firebase 적용: 배치 `props.uniformColor`가 Firebase 런타임 정규화에서 보존되도록 연결
- 유지: 피부, 머리, 넥타이, 배지, 바지, 신발, 외곽선, 자세, 위치, 회전, 크기, 애니메이션, 퀘스트 데이터, 타이틀 화면
