# 이미지 생성 지시문

공통 조건: 세로 9:16, 한 이미지에 한 장면, 선명한 한국 애니메이션·카툰 게임 홍보 일러스트. 피·고어·실사 공포·글자·로고·가짜 게임 UI 금지. 주인공은 `references/PLAYER_reference.png`의 분홍 단발, 붉은 눈, 빨간 재킷, 흰 셔츠, 노란 넥타이, 파란 치마·가방을 유지한다. 동료와 보스의 실제 게임 화면이 아니라 홍보용 콘셉트 해석이다.

| ID | 참조 자료 | 생성 지시 |
| --- | --- | --- |
| A01 | 주인공, 교실 | 햇살 드는 교실에서 뒤돌아보는 주인공. 뒤쪽에 초록색 블록형 좀비 학생 무리. 놀람과 모험의 시작, 대각선 원근과 역동적 시선. |
| A02 | 주인공, 연필 무기, 교실 | 주인공이 큰 연필을 던지는 순간. 화면을 가로지르는 연필, 밝은 속도선과 유쾌한 반격. |
| A03 | 주인공, 30cm 자 무기, 복도 | 자를 휘두르는 주인공의 횡방향 동작. 자 눈금이 보이고 복도 학생 좀비들이 밀려난다. 칼처럼 보이지 않도록 자의 형태를 강조. |
| A04 | 주인공, 치비코 아이콘, 교실 | 작은 치비코가 교실의 주인공 옆에서 분홍색 별·토끼 모양의 지원 효과를 발산. 밝고 장난스러운 협동. |
| A05 | 주인공, 하나코 아이콘, 복도 | 복도에서 넘어진 주인공이 하나코의 손을 잡고 하트빛 회복 효과를 받는다. 따뜻한 우정과 안도감. |
| A06 | 주인공, 이누콘 아이콘, 복도 | 강아지 이누콘이 주인공을 밝은 출구 쪽으로 이끌고, 뒤에는 우스꽝스러운 좀비 학생들이 쫓아온다. 속도감과 구조의 감정. |
| A07 | 주인공, B01 얼굴 텍스처, 복도 | 작은 주인공과 거대한 초록 블록형 B01 좀비 학생 보스의 대치. 학교 교복, 낮은 카메라, 과장된 크기. 잔혹함 없이 긴장감. |
| A08 | 주인공, 학교 출구 | 주인공이 되찾은 친구들과 손을 잡고 석양의 학교 문과 빛나는 포탈 쪽으로 달린다. 승리·해방·우정. |
| E01 | 학교 출구 | 캐릭터·글자·로고가 없는 석양 학교문 배경. 중앙 60%는 기존 로고와 행동 문구를 편집에서 얹을 수 있도록 차분하고 어둡게 비운다. |

편집자가 이미지-영상 변환 도구에 넣을 때는 각 장면에 1~3초의 패닝·줌만 부여하고, 캐릭터의 복장·얼굴·손·무기 형태가 변하지 않도록 고정한다. G01–G07은 반드시 실제 게임에서 별도 촬영한다.
