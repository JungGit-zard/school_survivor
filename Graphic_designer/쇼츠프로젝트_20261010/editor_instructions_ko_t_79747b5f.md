## I2V 적용 요령

- I2V 도구에는 `i2v_prompts_en_t_79747b5f.md`의 해당 ID prompt와 negative prompt를 그대로 붙여 넣는다.
- 모든 일러스트에 공통 negative prompt를 먼저 넣고, ID별 negative prompt를 추가한다.
- 얼굴·손·무기·복장은 source still 그대로 잠그는 설정이 있으면 켠다.
- 카메라 움직임은 1개만 선택한다: slow push, pan, pull-back, tracking 중 하나.
- 캐릭터를 새로 걷게 만들거나 전신 포즈를 크게 바꾸지 않는다. 짧은 쇼츠용 미세 모션만 사용한다.
- AI가 글자나 로고를 생성한 프레임은 사용하지 않는다.

## 실제 게임 캡처 요령

- 세로 쇼츠라도 원본 게임 화면은 실제 비율 그대로 캡처하고, 편집에서 크롭/배치한다.
- 촬영 전 디버그 표시와 마우스 커서를 제거한다.
- 브라우저 주소창이 들어간 화면은 사용하지 않는다.
- G03-G05는 0.5초라서 효과가 명확한 단일 순간이면 충분하다.
- 캡처 불가 기능은 가짜 합성 금지. rough cut에 `실제 캡처 필요` 마커를 남긴다.
