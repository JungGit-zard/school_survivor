# 30초 쇼츠 스토리보드

분위기: 알록달록한 학교 생존 액션. 좀비는 공포보다 친구를 다시 데려올 대상으로 표현합니다. 빠른 컷과 경쾌한 효과음으로 위기→반격→동료→보스→탈출을 연결합니다.

| 시간 | 화면 | 연출·편집 메모 |
| --- | --- | --- |
| 0–3초 | A01 교실 뒤돌아보기 | 종소리 뒤 급회전, 적들이 보이며 비트 시작. 자막 제안: `학교가 좀비로 가득?!` |
| 3–5초 | A02 연필 투척 | 손→연필→적 방향으로 짧은 패닝. 자막: `연필로 반격!` |
| 5–7초 | G01 실제 연필 플레이 | 명중 순간에 컷, 히트 효과음. |
| 7–9초 | A03 자 공격 | 자의 움직임을 따라 좌→우 패닝. |
| 9–12초 | G02 실제 무기 플레이 | 자·텀블러·플라스크의 실제 게임 컷을 비트에 맞춰 연결. |
| 12–13.5초 | A04 치비코 지원 | 핑크 빛 폭발에 맞춘 매치 컷. |
| 13.5–14초 | G03 실제 치비코 효과 | 실제 플레이로 바로 확인. |
| 14–15.5초 | A05 하나코 회복 | 따뜻한 하트 효과, 표정 클로즈업. |
| 15.5–16초 | G04 실제 하나코 효과 | 실제 플레이로 바로 확인. |
| 16–17.5초 | A06 이누콘 구조 | 탈출 방향으로 화면 이동. |
| 17.5–18초 | G05 실제 이누콘 효과 | 실제 플레이로 바로 확인. |
| 18–20초 | A07 B01 보스 대치 | 낮은 시점으로 보스 크기 강조, 한 박자 멈춤. 자막: `보스 등장!` |
| 20–23초 | G06 실제 보스전 | 핵심 공격·회피 장면 2~3개를 빠르게. |
| 23–25초 | A08 친구들과 탈출 | 포탈을 향한 전진, 음악 상승. 자막: `친구들과 함께 탈출!` |
| 25–27초 | G07 실제 탈출 포탈 | 게임 속 포탈 진입을 보여 주며 전환. |
| 27–30초 | E01 엔드카드 배경 | `references/logo.png`를 합성하고 `지금 플레이` 같은 짧은 행동 문구를 편집에서 추가. 실제 배포 링크/스토어 표시는 확정 후 별도 삽입. |

G01–G07은 비어 있는 촬영 슬롯입니다. 정지 이미지에는 패닝·줌·파티클 같은 편집 동작을 더할 수 있지만, 실제 게임 화면임을 암시하는 UI나 가짜 플레이는 추가하지 않습니다.
