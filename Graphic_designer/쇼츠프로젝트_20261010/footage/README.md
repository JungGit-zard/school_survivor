# 실제 게임 플레이 캡처 대기

이 폴더에는 아직 실제 게임 플레이 영상이 없습니다. 아래 클립을 실제 실행 화면에서 세로 9:16 편집에 맞게 촬영해 넣으세요. 콘셉트 일러스트나 생성 이미지를 실제 게임 화면이라고 표시하지 않습니다.

| 클립 | 길이 | 촬영 내용 |
| --- | --- | --- |
| G01 | 2초 | 연필이 적에게 명중하는 플레이 |
| G02 | 3초 | 자·텀블러·플라스크를 쓰는 플레이 |
| G03 | 0.5초 | 실제 치비코 효과 |
| G04 | 0.5초 | 실제 하나코 효과 |
| G05 | 0.5초 | 실제 이누콘 효과 |
| G06 | 3초 | 실제 B01 보스전 |
| G07 | 2초 | 실제 탈출 포탈 접근·진입 |

실제 플레이에서 해당 기능이나 캐릭터가 확인되지 않으면 해당 클립을 임의로 꾸미지 말고 편집 구성부터 조정합니다.
