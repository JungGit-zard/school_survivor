# 30초 쇼츠 오디오·SFX 큐시트

작성: 2026-10-10
담당: soundmini
범위: `timeline.csv`와 `storyboard.md` 기준 편집 제안. 게임 런타임 오디오, 정본 BGM, 라이선스 상태는 변경·확정하지 않는다.

## 전체 오디오 방향

- 톤: 알록달록한 학교 생존 액션. 공포보다 “위기 → 장난감 같은 반격 → 동료 합류 → 보스 압박 → 탈출” 리듬을 우선한다.
- 음악: 실제 트랙은 제안/편집 큐일 뿐이다. 사용자 제공 또는 권리 확인된 음악이 있을 때만 외부 편집에서 사용한다.
- SFX: 학교 종, 연필, 30cm 자, 텀블러, 플라스크, 동료 등장, 보스, 포탈을 짧은 WebAudio/ZzFX풍 또는 직접 제작 효과음으로 설계한다. 타 게임/Nintendo/Sega 음원 복제 금지.
- 음성: 필수 내레이션 없음. 보이스를 넣는다면 실제 대사보다 45–90ms pseudo-voice/Animalese 토큰만 아주 작게 사용하고, 의미는 자막과 화면이 전달한다.
- 믹스 기준: 자막 읽는 구간은 효과음 피크를 짧게, 음악은 -10~-14 dB 정도 ducking. 히트/포탈/보스 스팅어만 순간적으로 전면에 둔다.

## 비트 포인트 요약

- 0.0초: 학교 종으로 즉시 상황 설정.
- 3.0초: 연필 반격 시작, 음악/리듬 첫 진입 후보.
- 5.0초: 실제 연필 명중 확인, 첫 명확한 hit transient.
- 7.0초: 30cm 자 공격으로 무기 질감 변경.
- 9.0–12.0초: 실제 무기 플레이 몽타주, 비트당 SFX 1개 원칙.
- 12.0초: 동료 파트 시작, 밝은 음악 전환 후보.
- 14.0초 / 16.0초: 하나코·이누콘 전환은 회복/구조 색깔을 소리로 구분.
- 18.0초: 보스 등장, 1박 정지 + 저음 스팅어.
- 23.0초: 탈출 상승, riser 시작.
- 25.0초: 포탈 open.
- 27.0초: 엔드카드 로고 sting.

## 보이스 / 노보이스 가이드

- 기본 권장: 내레이션 없이 자막 + SFX 중심. 30초 쇼츠는 컷이 빨라 음성이 오히려 정보 과밀을 만들 수 있다.
- 보이스를 넣을 경우: 실제 문장 녹음 대신 동료별 감정 토큰만 사용한다.
  - 치비코: `삐`, `야`, `퐁` 계열, 45–65ms, pitch +6~+10.
  - 하나코: `아`, `링`, `음` 계열, 60–90ms, 부드러운 envelope.
  - 이누콘: `헥`, `멍`, `왁` 계열, 45–70ms, pitch +3~+7.
  - B01: `흠`, `둥`, `카` 계열, 90–140ms, pitch -6~-12.
- 금지: 실제 배우·캐릭터·유명인 음성 모사, 알아들을 수 있는 긴 대사, 타 게임 Animalese/효과음 샘플 복제.

## 믹스·덕킹 가이드

- 광고 최종 편집 기준으로 음악은 SFX보다 뒤에 둔다. 스마트폰 스피커에서 히트음과 종소리가 먼저 들려야 한다.
- 자막 또는 CTA 문구가 나오는 순간: 음악 -10~-14 dB, 장식 SFX -3~-6 dB.
- 보스 18초: 음악을 0.2–0.4초 ducking해서 저음 stomp와 경고음을 확보.
- 포탈 25–27초: riser와 포탈음을 동시에 크게 만들지 않는다. 포탈 open은 low-mid, 성공 chime은 high로 분리.
- 최종 loudness는 플랫폼 편집 단계에서 맞춘다. 이 문서는 제작·편집 큐이며 LUFS 실측 완료를 주장하지 않는다.

## 라이선스·적용 경계

- 이 큐시트는 제안 문서다. 게임 오디오 파일, `SOUND_MAP`, 정본 `title_bgm.m4a`, 런타임 코드는 변경하지 않았다.
- 실제 음악/효과음 파일은 아직 확정하지 않는다. 사용 시 직접 제작, 직접 녹음, CC0/public-domain, 또는 사용자가 권리 확보한 파일만 후보로 둔다.
- Nintendo/Sega/타 게임의 멜로디, 샘플, UI음, 보이스 토큰을 복제하지 않는다. 고전 게임 레퍼런스는 짧고 명확한 제약 기반 설계 원리로만 사용한다.
