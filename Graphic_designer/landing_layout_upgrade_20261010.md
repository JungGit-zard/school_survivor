- 기존 라이브 첫 화면: `C:/Users/admin/AppData/Local/Temp/landing-before-20261010.png` (desktop 1264×568), `C:/Users/admin/AppData/Local/Temp/landing-mobile-before-20261010.png` (mobile 390×844).
- 개선 데스크톱 첫 화면: `C:/Users/admin/AppData/Local/Temp/landing-after-desktop-20261010.png`. 이 중간 캡처에서 발견한 하단 중복 모바일 시작 버튼은 후속 수정으로 제거했다. 최종 화면·동작 검증 결과는 별도 QA 기록을 따른다.
- 큰 hero와 여백을 압축하여 제목·설명·주 게임 시작 버튼이 첫 화면에 들어오도록 구성했다. 흰 덮개와 홈페이지 장면 투명도를 조정하여 오른쪽 기존 3D 장면을 더 명확하게 표시한다.
- 주 게임 시작 버튼을 우선하고 기존 보조 링크는 모바일 두 열로 묶었다. 상단 중복 시작 버튼과 본문 중복 모바일 시작 버튼을 정리했으며, hero를 지나친 뒤에만 고정 시작 버튼을 제공한다.
- 모바일 메뉴는 브랜드/언어와 횡스크롤 메뉴 두 줄로 구성한다. 메뉴 대상 크기를 최소 44×44px로 유지하고 고정 메뉴 아래의 섹션 이동 여백을 확보했다.
- 기존 카피·번역·미디어 콘텐츠·원화·배경 자산을 보존했다. 게임 타이틀 화면, 캐릭터 모델, BGM, 인증 및 Firebase 구현은 변경하지 않았다.
