실제 게임 녹화 체크리스트
실제 전투 영상은 미녹화·미포함. 기존 검색에서 바로 쓸 전투영상은 확인하지 못했다. AI로 gameplay를 생성하지 않는다.
현재 게임 주인공·일반 좀비·치비코·하나코·이누콘·B01 전신 정면/측면 캡처부터 준비. 소스 코드/얼굴 텍스처만으로 현재 Firebase 외형 확정 금지. Studio 파라미터 수정/Apply 금지.
G01 연필 명중 2초. 애니와 진행 방향 맞춤.
G02 자/회전 텀블러/플라스크 착탄·웅덩이 총 3초.
G03 치비코 연필 0.5초 / G04 하나코 회복 0.5초 / G05 이누콘 끌어내기·회복 0.5초.
G06 B01 실제 보스전 3초 / G07 실제 포탈 2초.
각 구간 앞뒤 1~2초 여유 녹화. 원본 게임 비율로 확보 후 9:16 안에 배치. HUD/공격이 잘리면 전체 게임 프레임을 보존하는 구성을 쓴다. 가짜 HUD/보스/승리 화면 생성 금지.
일반 플레이를 녹화하며 실제 Firebase 정본을 바꾸는 테스트·디버그·Apply를 하지 않는다. 데이터 테스트 필요 시 프로젝트 전체 스냅샷/완전복원 규칙 선행.
