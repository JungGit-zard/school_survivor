- 작성일: 2026-08-25

## 공통 구현 계약

현재 `Game.jsx`의 공용 3광원은 모든 스테이지에서 그대로 유지한다. 이 3개는 플레이어와 적의 기본 분리를 보장하는 기반이며, Stage별 연출은 아래의 **고정 로컬 광원 0~2개**만으로 만든다.

| 공용 광원 | 현재 값 | 유지 이유 |
| --- | --- | --- |
| Ambient | `#6D6780`, intensity `0.38` | 검은 그림자에 적·무기·바닥 경고가 사라지는 것을 막는 최소 fill |
| Directional key | position `[-10, 22, 12]`, intensity `3.2` | 카메라 쪽(+Z)에서 플레이 공간과 캐릭터 전면을 읽게 하는 주광 |
| Directional rim | position `[10, 12, -10]`, `#FFE2B0`, intensity `0.85` | 북쪽 배경과 보스 외곽을 약하게 분리하는 역광 |

- 성능 상한은 **공용 3 + Stage local 최대 2 = 동시에 최대 5광원**이다.
- local light는 모두 `castShadow={false}`다. 기존 씬의 그림자 map을 늘리지 않으며, 보스 추적등·캐릭터 부착등·발사체별 real light는 추가하지 않는다.
- Spot은 승인 좌표를 향하기 위해 active Spot마다 정적·비가시 `Object3D` target 1개를 허용한다. 이는 helper mesh나 draw call이 아니며, `useFrame`·추적·프레임별 allocation 없이 Stage 전환 시 mount/unmount된다. Point는 고정 landmark에만 둔다. 즉 카메라·보스·발사체를 따라 움직이지 않는다.
- fog, 전체 bloom, 실시간 반사(SSR), environment-map 갱신은 기본값 `off`다. 위험 표시는 이미 있는 meshBasicMaterial 바닥 텔레그래프와 HUD/VFX가 담당한다.
- 밝기 우선순위는 언제나 **즉사/피해 경고 > 플레이어·무기 > 보스 > 지형 장식 > 먼 배경**이다. 연출 조명은 이 순서를 뒤집지 않는다.

## Stage 1 — 교실: “수업이 멈춘 뒤, 창문 쪽만 아직 밝은 교실”

한 줄 무드: **초기 생존을 배우는 장소답게, 차가운 아침 창빛과 따뜻한 교실 전등 잔광이 중앙 안전 공간을 또렷하게 지킨다.**

### 공간·밝기 계층

- 실제 전투 경계는 X `±10`, Z `±14.4`의 좁은 직사각 교실이다. 중앙은 의도적으로 비어 있고, 책상·의자·쓰러진 학생은 벽 쪽에 몰려 있다.
- 플레이어가 시작하는 남쪽/카메라 쪽과 중앙은 체감 밝기 `1.0` 기준을 유지한다. 북쪽 창가와 동쪽 책상군은 `0.80`, 가장자리 학생·전도 의자는 `0.55~0.65`까지만 낮춘다.
- 색온도는 북쪽 창빛 `6500K` 계열의 옅은 청백색, 남쪽 교실등 `3900K` 계열의 담황색 두 층만 사용한다. 피·경고·무기 색을 대신하는 강한 빨강/주황 조명은 금지한다.

### 구현 확정 조명

| local 광원 | 배치 / 조준 | 값 | 역할 |
| --- | --- | --- | --- |
| 창가 Spot | position `[-6.8, 5.4, -10.8]` → target `[0, 0, -2.4]` | color `#D7EAFF`, intensity `0.42`, distance `12`, angle `0.70 rad`, penumbra `0.50`, `castShadow=false` | 북쪽 쓰러진 학생·책상 윤곽을 읽게 하되 중앙 전투 공간을 백색으로 날리지 않는 창빛 |
| 교실등 Point | position `[1.8, 4.3, 7.6]` | color `#FFE0AD`, intensity `0.32`, distance `8.0`, decay `2`, `castShadow=false` | 플레이어 시작 방향, 연필 투척 궤적, 남동쪽 책상 근처를 안전하게 분리 |

### 보스·위험 cue 충돌 방지

- B01은 Stage 1에서 추격/돌진 압박만 사용한다. 보스 등장과 돌진에는 새 real light를 만들지 않는다.
- B01 스폰 `150초`, 탈출 포털 `210초`에는 현재 bossSpawn/portal VFX 및 HUD만 사용한다. 창가 Spot·교실등 Point의 색·세기는 고정한다.
- 적이 빽빽한 초반에는 추가 조명을 펄스하지 않는다. 적 실루엣·연필·XP 색의 대비가 우선이다.

### 모바일 shot list

1. `360×800`: 시작 위치에서 플레이어, 중앙 빈 공간, 북쪽 창가 책상과 남동쪽 책상이 서로 다른 밝기 층으로 보인다.
2. `430×932`: 북쪽 끝의 쓰러진 학생이 배경 장식으로만 보이고 E01 윤곽·연필이 그보다 먼저 읽힌다.
3. B01 등장/돌진: 화면에 경고·보스·플레이어가 동시에 있을 때 새 흰 번짐이나 역광 역전이 없다.
4. 적 밀도 최대: 5개 초과 local light, 그림자 map, bloom이 생기지 않고 HUD 가독성이 유지된다.

## Stage 2 — 복도: “비상등과 사물함 사이의 긴 시선”

한 줄 무드: **좁고 긴 복도는 차가운 끝빛으로 깊이를 주되, 중앙 통로와 B02의 청록 봉쇄선은 어떤 조명보다 먼저 보이게 한다.**

### 공간·밝기 계층

- 실제 전투 경계는 X `±7.5`, Z `±19.2`다. 사물함·분실물 보드·청소 카트·책상은 통로에 산재해 있으므로 양쪽 벽이 밝아지면 회피 경로가 오히려 묻힌다.
- 이동 통로 중앙은 `1.0`, 카메라 쪽 남단은 `0.85`, 북쪽 끝문과 벽 장식은 `0.60~0.70`, 사물함 면은 `0.65`를 목표로 한다.
- 색온도는 비상등 청록 `5600K` 계열과 사물함 보조광 `4500K` 중성 회색만 사용한다. 노란/주황은 B03 전용 레인 색과 혼동될 수 있으므로 Stage 2 local light에 사용하지 않는다.

### 구현 확정 조명

| local 광원 | 배치 / 조준 | 값 | 역할 |
| --- | --- | --- | --- |
| 북단 Spot | position `[0, 5.2, -17.2]` → target `[0, 0, -9.8]` | color `#C7F3F5`, intensity `0.38`, distance `13`, angle `0.58 rad`, penumbra `0.56`, `castShadow=false` | 북쪽 끝문과 길이감을 주되 E04 탄·B02 봉쇄선 청록보다 채도가 낮은 배경 practical |
| 서측 사물함 Point | position `[-5.7, 3.2, 2.0]` | color `#D8E5EA`, intensity `0.22`, distance `6.2`, decay `2`, `castShadow=false` | 중간 사물함과 분실물 보드의 형태만 살리고 중앙 통로를 밝히지 않는 낮은 fill |

### 보스·위험 cue 충돌 방지

- B02는 `150초`에 등장하며 HP `70%`, `35%`에서 2개 봉쇄선을 만든다. 텔레그래프 `1200ms`와 active `1500ms`의 정본 색 `#22CBD2`/`#24EDF0`이 Stage local light보다 항상 더 밝고 채도 높게 남아야 한다.
- B02 봉쇄선이 활성화되어도 local Spot/Point는 색·세기·위치를 변경하지 않는다. 보스 주위 halo 또는 이동 조명은 0개다.
- Stage 2 E04의 원거리 탄은 청록 배경과 섞일 수 있으므로 북단 Spot의 intensity는 `0.38`을 넘기지 않는다. 발사체/피해 VFX는 tone-mapped false의 기존 표시를 우선한다.

### 모바일 shot list

1. `360×800`: 남쪽에서 북쪽 끝문까지 통로가 끊기지 않고, 중앙 빈 lane이 양쪽 사물함보다 먼저 읽힌다.
2. E04 첫 진입 이후: 투사체 실루엣과 북단 Spot의 색·밝기가 겹쳐 사라지지 않는다.
3. B02 HP `70%` 및 `35%`: 두 봉쇄선의 청록 텔레그래프가 사물함/바닥/보스보다 먼저 인식된다.
4. B02 active `1500ms`: 폭이 `1.2`인 위험선 전체와 플레이어 발 위치를 한 화면에서 구분할 수 있다.

## Stage 3 — 체육관: “정전 직전의 코트, 마지막 경기의 압박”

한 줄 무드: **넓은 나무 코트에는 관중석 대신 비어 있는 경기 조명을 남겨, B03의 왕복 레인이 한눈에 보이는 결전 공간으로 만든다.**

### 공간·밝기 계층

- 실제 전투 경계는 X `±7.5`, Z `±19.2`다. 나무 마루·흰 코트 라인·파란 벽 stripe·북남 골대가 이미 강한 공간 단서이므로, 광량보다 좌우 대비를 조절한다.
- 센터 서클과 플레이어 전투 구역은 `1.0`, 양측 벤치·매트는 `0.68~0.75`, 북남 골대·점수판은 `0.78`, 천장/상단 벽은 `0.40~0.50`을 목표로 한다.
- 색온도는 경기장 상부광 `5200K` 중성 백색과 남동쪽 벤치 쪽 `3500K`의 아주 약한 따뜻한 rim만 사용한다. 코트 라인 `#F4F1E8`, 페인트 존 `#C1533B`, B03 레인 경고의 황색을 조명으로 재현하지 않는다.

### 구현 확정 조명

| local 광원 | 배치 / 조준 | 값 | 역할 |
| --- | --- | --- | --- |
| 센터코트 Spot | position `[-0.8, 7.0, -1.2]` → target `[0, 0, 0]` | color `#E6F1FF`, intensity `0.44`, distance `15`, angle `0.86 rad`, penumbra `0.62`, `castShadow=false` | 센터 서클·플레이어·나무 마루의 기본 대비를 정리하되 흰 코트 라인을 과노출시키지 않음 |
| 남동쪽 벤치 Point | position `[5.8, 3.7, 10.8]` | color `#FFE1B8`, intensity `0.24`, distance `7.0`, decay `2`, `castShadow=false` | 쓰러진 벤치·장비 spill과 남쪽 골대 방향을 구분하는 저강도 practical |

### 보스·위험 cue 충돌 방지

- B03는 `150초`에 등장하고 HP `65%`, `30%`에서 왕복 오래달리기를 쓴다. 레인 텔레그래프 `1250ms`는 `#F5B83D`, 왕복 active는 `#FFD34E`/`#E6A81F`이므로 센터 Spot은 `#E6F1FF`·`0.44`에서 절대 펄스하지 않는다.
- 레인 폭은 `1.2`, 플레이어 현재 Z에 맞춰 X 전체를 가른다. 따라서 레인·보스·플레이어보다 밝은 무대 조명이나 노란 Point는 0개다.
- B03 왕복 이후 stun `1200ms`에도 광량을 올리지 않는다. 플레이어의 반격 시간은 보스 상태와 레인의 낮은 opacity로 전달한다.

### 모바일 shot list

1. `360×800`: 센터 서클, 흰 코트 라인, 플레이어, 북쪽 골대가 서로 분리되고 마루의 줄무늬가 화면을 흔들어 보이지 않는다.
2. B03 등장: 보스 외곽이 공용 rim으로 읽히고, 센터 Spot이 머리 위 강한 흰 후광을 만들지 않는다.
3. HP `65%`/`30%` 텔레그래프: 플레이어 Z를 가로지르는 황색 레인이 센터 서클과 코트 페인트보다 먼저 읽힌다.
4. 왕복 2패스와 stun: 레인 색 전환, 보스, HUD가 겹쳐도 local light가 색 신호를 가리지 않는다.

## 구현·검수 순서

1. `Game.jsx`에 stageId별 고정 local light 컴포넌트를 하나만 배치한다. 공용 3광원의 값·순서·그림자 설정은 변경하지 않는다.
2. Stage 1, 2, 3을 각각 진입해 모든 local light 수가 정확히 2개 이하인지 확인한다. Stage 전환 시 이전 Stage local light가 남아 있으면 실패다.
3. `360×800`, `430×932`에서 위 shot list를 캡처하고, B01 돌진·B02 봉쇄·B03 왕복 레인 중 조명보다 기존 텔레그래프가 우선 인지되는지 확인한다.
4. draw call/frame time을 기존과 비교한다. shadow map 추가, fog, bloom, boss-follow light, projectile light가 발견되면 이 계획의 구현은 실패다.

이 문서는 조명 구현의 단일 시작값이다. 사용자가 수치·색·위치를 지정하면 임의 보정, clamp, fallback 없이 지정값을 그대로 우선한다.
