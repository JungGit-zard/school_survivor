## 소스 수정

- `firebaseRanking.js`: 실제 이벤트 호출 때 플레이 시각을 고정한다. Firebase transaction으로 높은 기존 점수·시간·클리어를 보존하면서 `lastPlayedAt`을 최신 실제 이벤트로 갱신한다. 낮은 점수나 0점 재입장도 마지막 플레이 시각을 잃지 않는다. 같은 요청 재시도는 횟수·점수를 더하지 않는다. 실제 SDK 경로는 transaction, 기존 주입 테스트 어댑터만 get/set 호환 경로다.
