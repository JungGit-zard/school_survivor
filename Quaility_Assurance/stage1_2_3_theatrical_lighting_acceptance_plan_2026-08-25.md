## 2. 실행 환경과 공통 측정법

### 필수 장면·반복

각 스테이지를 아래 장면에서 캡처/영상으로 검증한다. 각 조건은 동일 빌드·카메라 거리에서 3회 반복하고, 화면 밝기 100%와 50% 모두 기록한다.

| 뷰포트 | 필수 장면 |
| --- | --- |
| 320×568 (세로 협소) | 일반 웨이브, 보스 100%/50%/10% HP, 플레이어 저HP, 무기·발사체 동시 표시, 해당 보스 필살기 예고/활성 구간 |
| 412×839 (세로 일반) | 위와 같은 장면 + 바닥 중앙/가장자리, 벽·소품 근접, 화면 가장자리에서 적·발사체가 진입하는 구간 |

정지 화면만으로 통과시키지 않는다. 30fps 이상 녹화에서 예고부터 피해/종료까지의 시간 신호를 확인한다. 실제 기기에서 색각 보정이 불가하면 소스 영상의 protanopia, deuteranopia, grayscale 변환본을 추가 증거로 남긴다.

### 수치 판정법

1. **명도(Y)**: 캡처의 sRGB를 선형 변환 후 `Y = 0.2126R + 0.7152G + 0.0722B`로 계산한다. 비교 대상의 최소 2 CSS px 배경 띠를 따로 채취한다.
2. **형태 대비**: 플레이어·적·보스의 본체 또는 외곽선 픽셀군과 바로 옆 배경 띠의 휘도비가 `3:1` 이상이면 PASS다. 위험 텍스트·필살기 예고·HP 수치는 `4.5:1` 이상이어야 한다.
3. **밝은 바닥/어두운 모서리**: 각 Stage의 바닥 중앙 20%와 화면에서 보이는 네 모서리의 바닥/벽 10%를 측정한다. 평균 명도는 `Y중앙 0.32~0.78`, `Y모서리 0.12 이상`, 그리고 `Y중앙 - Y최저모서리 0.12~0.42`여야 한다. 모서리는 분위기용으로 어두워질 수 있으나 조작·적·경계가 사라지는 검은 구멍이면 FAIL이다.
4. **관찰자 확인**: 위 도구 측정이 불가능한 경우 3명의 관찰자가 1초 이내에 플레이어, 가장 가까운 위협, 해당 보스 위험 신호를 지목해야 한다. 이는 정성 보류 증거이며 수치 PASS를 대체하지 않는다.

1. **P0 — 생존 정보 소실:** 플레이어·가장 가까운 적·B01/B02/B03·HP·필살기 예고 중 하나라도 1초 내 식별 실패, 4.5:1 위험 표식 실패, 또는 색각/회색조에서 위험이 사라짐. 해당 스테이지 조명은 NO-GO다.
