# 4스테이지 고도화 문서 독립 검토

작성일: 2026-10-22 · 검토: Main Advisor · 범위: 문서 납품 검토

## 검토 결과

종합 기획 231줄, 그래픽·신규 좀비 상세안 238줄, 오디오·피드백안 138줄 및 연결 목차를 직접 읽고 대조했다. 네 문서의 상대 링크 총 32개는 대상 파일이 존재하며, 소스 행 번호 링크의 범위 초과는 없다. UTF-8 디코드, 대체 문자, 줄 끝 공백, 코드 블록 닫힘 검사에서 오류가 없었다.

현재 소스·과거 a9 추출본·로컬 원격 추적 참조·실제 운영 상태를 구분했다. 현재 작업본의 clear 기반 해금과 사용자 요구의 boss-only 해금 차이를 기획 인계에 남겼으며, 이번 문서 작성으로 런타임을 수정하거나 운영 문제가 복구되었다고 주장하지 않는다.

주방장 보스의 별도 국물 폭발 종료 후 돌진 진입과 순수 전환 모듈의 1000ms 상수를 구분했다. 중앙 압력솥과 보스 국물 위험을 구분하고, 맵 크기·150/205/210초 주요 시각을 임의 변경하지 않는 제안임을 확인했다.

신규 좀비 네 안은 외형·크기 후보·준비/공격/회복·판정·대응·등장 구간·개체 교체·구현 접점·취소/슬롯 재사용 기준을 포함한다. 우선 후보 1종과 선택 후보 3종을 구분한다. 종합 문서의 이전 범위 표현을 최신 사용자 요청에 맞췄고, 오디오 가칭을 그래픽 문서의 동일 네 종류에 맞춰 정리했다. 방패 면역·카트·장판 등 별도 기능을 암시하던 불일치를 제거했다.

## 조사 시점 주의

Worker 근거 참조는 canonical HEAD `6f416d83`의 dirty 작업본, a9 추출본, 당시 로컬 `origin/zombie_only` = `ef9b701e`다. Advisor는 별도 문서 전용 checkout에서 실제 원격 `85371272e51a2ef756d3816fa2d87c71657a0ffb`를 fetch하고 Stage4 설정을 대조했다. 이것이 모든 소스·실효 Firebase 값을 최신판 기준으로 재검증했다는 뜻은 아니다.

문서 커밋은 이 별도 최신 원격 기반 checkout의 `zombie_only`에서 명시된 문서 경로만 대상으로 한다. canonical의 기존 브랜치·dirty 파일·index를 정리하거나 되돌리지 않는다.
