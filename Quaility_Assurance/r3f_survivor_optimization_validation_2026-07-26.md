# R3F Survivor 최적화 검증 기록 - 2026-07-26

## 검증 범위

- 공유 공간 격자를 재사용하는 무기 타깃팅과 splash 후보 수집. 넓은 반경의 거리순 수집은 고정 최대 힙과 제자리 heapsort를 써서 O(N log N)으로 처리하며, 호출당 할당 없이 거리·동점 순서를 보존한다.
- Zustand 매 프레임 시간 발행 제거 및 HUD 최대 10Hz 발행
- pooled zombie/projectile 수동 화면 경계 컬링, `mesh.count` 압축, near/mid/far LOD
- 2/4/8/12 프레임으로 분산한 AI 시야 검사

## 통과한 검증 근거

- 200명 적 상황의 타깃팅 회귀 비교 테스트가 통과했다.
- 200명 넓은 반경 정렬 비교 수는 4,000회 미만이며, 거리·동점 순서 보존과 호출당 할당 없음을 확인했다.
- 집중 테스트: 98개 통과.
- 전체 테스트: 156개 파일, 1,351개 테스트 통과.
- 프로덕션 빌드 통과.
- B02 게이트 통과.
- 로컬 브라우저 E2E: Stage 1 시작→전투(00:02)→레벨업(00:16)까지 통과. 좀비 3D toon, 검은 outline, HP 바가 정상 표시됐다.
- 위 E2E에서 browser console warning/error는 0건이었다. Firebase/Graphics Studio 저장 조작은 하지 않았다.

## 불변조건 확인 대상

- 정확한 게임 시간 판정은 HUD 발행 빈도와 분리되어야 한다.
- 컬링과 LOD는 렌더링 비용만 바꾸며, 물리·이동·피해 판정·무기 규칙을 바꾸면 안 된다.
- toon 표현과 외곽선은 near/mid/far 모든 단계에서 유지되어야 한다.
- Firebase, Firebase Authentication, Graphics Studio 데이터는 테스트하거나 변경하지 않았다.

## 아직 미실시 — 통과 아님

- 실제 목표 기기의 장시간 FPS, 프레임 시간, 메모리 사용량 계측
- 실제 기기에서 밀집 전투 중 화면 경계 컬링 누락/과잉 컬링을 포함한 경계 스트레스 관찰
- 실제 기기에서 near/mid/far 모든 LOD 거리의 실루엣, 외곽선, HP 바 가독성 확인
- 장시간 플레이에서 AI 시야 검사 분산이 체감 반응성과 난이도에 미치는 영향 확인

위 항목은 이번 검증에서 수행되지 않았으므로 통과로 판정하지 않는다. 실기기 계측 결과와 재현 가능한 측정 조건을 추가한 뒤 별도 QA 판정을 해야 한다.
