# Stage 2 경비원 추격 좀비떼 컨셉

## 한 줄 컨셉

스테이지 2 복도 화면 한쪽 끝에서 바바리맨 좀비 1기가 달아나고, 경비원 좀비 6기가 뒤를 쫓아 반대쪽 끝까지 직선으로 질주하는 코믹 추격 이벤트다.

## 정본 구성

- 전용 타입: `RZT`(도망가는 바바리맨 좀비), `RZG`(추격하는 경비원 좀비).
- 한 무리: `RZT` 1기 + `RZG` 6기, 총 7기.
- 대형: `RZT`가 선두에 서고 `RZG`는 뒤쪽 2열 × 3행으로 추격한다.
- 스테이지 제한: `stage2`에서만 생성한다. 스테이지 1·3·4 및 일반 웨이브에는 넣지 않는다.
- 등장 시점: 42초, 88초, 136초, 216초. 170~190초의 무작위 보스 등장 구간과 겹치지 않는다.

## 이동 규칙

- 등장할 때 네 화면 끝(위·아래·왼쪽·오른쪽) 중 하나를 무작위로 고른다.
- 선택한 끝의 무작위 지점에서 시작해 반대쪽 끝의 무작위 지점을 목표로 삼는다.
- 시작점과 목표점을 이은 하나의 정규화된 방향 벡터를 무리 전체가 사용한다. 따라서 가로·세로·대각선을 포함한 다양한 각도로 화면을 횡단한다.
- `RZT`는 `RZG`보다 약간 빠르게 달려 추격 간격이 서서히 벌어진다.
- 두 타입 모두 벽·책상·사물함 등 스테이지 장애물과 충돌하지 않고 그대로 통과한다.
- 맵 반대쪽 바깥 여유 경계를 완전히 지난 순간 보상 없이 자동 제거한다. 플레이어에게 죽은 경우에는 일반 처치 보상을 적용한다.
- 이동 구현은 스테이지 3 `runZombieCrew`의 풀 엔티티, 고정 진행 방향, 화면 횡단 제거 구조를 확장한다. 별도 이동 시스템은 만들지 않는다.

## 구현 경계

- 스테이지 2 런타임 필터는 보스 이벤트와 이 추격 이벤트만 발화시킨다. 기존에 휴면 상태인 `swarm`, `ring`, `pincer` 이벤트를 함께 켜지 않는다.
- 기존 스테이지 3 `RZL`/`RZC`의 고정 대각선 이동, 수치, 등장 시점, 장애물 처리에는 손대지 않는다.
- 새 타입 코드는 기존 보스 타입 코드 뒤에 추가해 기존 코드 번호를 바꾸지 않는다.
- 그래픽 변형은 `ZombieMesh.jsx`의 `ZBlock` 자식 구조 → `StudioTunedGroup` → 숫자 child path → Firebase Studio 값 적용이라는 기존 Zombie E01 공용 체인만 사용한다.
- 독자 변형 함수, 독자 파트 ID, 로컬 저장, 기본값 대체, fallback은 만들지 않는다.

## 완료 기준

1. 스테이지 2에서만 네 차례 생성된다.
2. 각 생성마다 시작 끝과 횡단 각도가 무작위이며, 무리는 선택된 반대쪽 끝까지 달린다.
3. 장애물을 만나도 속도·방향이 바뀌지 않고 그대로 통과한다.
4. `RZT` 1기 앞, `RZG` 6기 뒤의 추격 실루엣이 유지된다.
5. 반대 경계를 통과하면 보상 없이 제거되고, 정상 처치 때만 보상이 나온다.
6. 스테이지 3 러닝 좀비 크루와 기존 보스/웨이브 동작은 변하지 않는다.
7. 두 모델이 Graphics Studio 카탈로그에 나타나고, 다른 모든 좀비와 동일한 공용 변형 방식으로 Apply된다.
