# 오늘의 신규 4컷 만화 — 청소의 비밀

- 날짜: 2026-10-13. 기존 5편 수정이 아닌 신규 6번째 이야기 한 편.
- 범위: 동일한 4컷 그림에 한국어·영어·일본어·중국어 간체·베트남어·인도네시아어 대사를 각각 넣는다.
- 기존 치비 그림체, 분홍 머리 주인공, 녹색 네모 좀비와 교복을 유지한다. 좀비의 인간 변신이나 마법으로 해결하지 않는다.
- 설정→행동→결과→반전: 더러운 교실을 청소하려고 빗자루를 건넸더니, 좀비는 먼지를 매트 밑에 숨겼다. 여주가 매트를 들춰 발견한다.

| 컷 | 필요한 그림 | 한국어 |
|---|---|---|
| 1 | 여주가 더러운 바닥을 가리킨다. 문 앞 파란 매트가 미리 보여야 한다. | 청소부터 하자! |
| 2 | 같은 여주가 같은 좀비에게 빗자루를 건넨다. | 먼지는 한곳에 모아! |
| 3 | 좀비가 같은 매트 아래로 먼지를 민다. 독자는 행동을 보지만 여주는 눈을 감고 기뻐한다. | 벌써 깨끗해졌네? |
| 4 | 여주가 같은 매트를 들어 먼지 더미를 발견한다. 좀비는 들켜 당황한다. | 매트 밑에 숨겼잖아! |

각 언어는 동일한 지시와 놀람·발견의 의미다. 인도네시아어 마지막 문장은 주어 생략 수동 표현이며, 좀비의 행동이 그림으로 명확하므로 짧은 구어체로 이해할 수 있다. 국가별 별도 이야기를 만들지 않는다. 정기 실행 등록·활성 상태와 홈페이지 연결은 별도 구현 담당이 확인한다.
