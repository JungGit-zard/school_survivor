# Stage 3 0.25초 녹색·웃는 좀비 보강

## 확정 규칙

- 대상은 Stage 3만이다.
- 0.25초부터 149.75초까지 0.25초 간격이며 150.00초는 포함하지 않는다.
- 각 시각에 E01 3마리 뒤 E07 3마리를 추가한다.
- 총 599틱, E01 1,797마리, E07 1,797마리, 합계 3,594마리다.
- 기존 Stage 3 버스트·formation·RZL·B03·마틸다·도지·오버타임과 Stage 1/2/4는 변경하지 않는다.

## 구현 결정

1,198개의 일회성 이벤트를 런타임 표에 펼치지 않는다. E01/E07 반복 descriptor 두 개만 Stage 3 버스트 표에 넣고, 기존 RAF 스케줄러가 누적 틱을 소비한다. 따라서 프레임마다 대량 이벤트를 순회하거나 별도 interval을 만들지 않는다.

기존 풀 FIFO는 프레임당 최대 3마리를 drain한다. 새 보강의 정상 유입은 초당 24마리이므로 60fps 기준 drain 여유(초당 최대 180마리) 안에서 기존 `addEnemies(..., true, token)` 소비 경로로 들어간다. 기존 전역 150마리 동시 상한은 모든 스폰에 이미 적용된 안전 규칙으로 보존한다.

## 인수 기준

- Stage 3 런타임 버스트 표에 `stage3QuarterSecondE01E07` 반복 descriptor 2개(E01, E07)가 포함된다.
- 런타임 발화 시 0.25초~149.75초, 0.25초 간격, 599틱을 소비한다.
- 각 틱은 E01 3마리와 E07 3마리를 기존 `SCHEDULE_BURST` / pooled `addEnemies(..., true, token)` 경로로 보낸다.
- 합산 추가량은 E01 1,797마리 + E07 1,797마리 = 총 3,594마리다.
- Stage 1/2/4 버스트 표와 Stage 3 기존 B03/RZL/formation/13개 앵커 정본은 보존된다.
- 기존 Stage HP 1.3배 사다리 검증은 보강 descriptor를 제외한 base 이벤트 기준으로 유지된다.

## Balance_QA_Mini QA handoff

- Stage 3 실기기/모바일에서 0.25초 이후 초당 24마리 유입이 전역 150마리 상한과 풀 drain 안에서 끊김 없이 소비되는지 확인한다.
- 60fps 기준 drain 여유는 초당 최대 180마리지만, 저사양 단말에서 프레임 드랍 시 `consumedRepeatBurstTicksRef`가 누락 없이 catch-up하는지 0.25초, 30초, 135초, 149.75초, 150초 경계를 확인한다.
- 150.00초 이후 새 반복 보강이 추가 발화되지 않는지 확인한다. `repeatingBurstTickAt`은 150초 이상 프레임 지연 시 마지막 598틱을 소비하기 위한 catch-up만 허용한다.
- Stage 3 보스 B03 135초, 기존 RZL 40/108/144/168초, formation 60/120/150/184초가 새 반복 보강과 함께 유지되는지 확인한다.
