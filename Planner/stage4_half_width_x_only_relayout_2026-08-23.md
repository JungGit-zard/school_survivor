# Stage 4 가로 절반·X 전용 재배치 기획 정본

- 사용자 지정값: `mapHalfX 14.4 → 7.2`, `mapHalfZ 16` 유지.
- 바닥: `14.4 × 32 units`, 타일 `0.8 × 0.8 units`, UV 반복 `18 × 40`.
- Stage 4 authored 배치는 X만 기존값의 `0.5×`를 기준으로 축소한 뒤, 새 벽과 소품 사이에 플레이어만 들어가는 틈이 없도록 X만 최소 조정한다.
- Y, Z, 회전, 스케일, props, blocking, 타입, 개수, 순서는 변경하지 않는다.
- 중앙 압력 가마솟은 `[0, 0, 0]`, 플레이어 시작은 `[0, 0, 7]`로 유지한다.
- 기존 전체 폭 Firebase 런타임 배치는 `|x| > 7.2`인 항목이 하나라도 있을 때만 배열 전체의 X를 메모리에서 1회 `0.5×` 해석한다. Firebase 데이터는 쓰거나 변경하지 않는다.
