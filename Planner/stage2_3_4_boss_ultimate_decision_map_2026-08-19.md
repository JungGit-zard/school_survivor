# Stage 2·3·4 보스 필살기·영구 패시브 결정 맵

- 작성: Level_Mini
- 날짜: 2026-08-19
- 상태: **사용자 검토용 최종 추천안 / 미구현**
- 범위: B02·B03·B04의 필살기와 처치 보상 영구 패시브. 이 문서는 기획만 담으며 런타임·Firebase·모델·Studio·오디오 파일은 변경하지 않았다.

## 0. 고정 시간·공통 계약

| 항목 | 정본 |
|---|---|
| 보스 등장 | B01~B04 모두 150초(2:30). 변경 금지. |
| 마틸다 | 205초 경고, 210초 실제 등장. |
| 신규 필살기 시전 | `elapsed >= 200초`이면 어떤 보스도 새 시전을 시작하지 않는다. 이미 진행 중인 필살기는 200초 전에 끝나도록 설계한다. |
| Stage 3 overtime | 225초 첫 보강. 보스 필살기는 overtime에서 재시작하지 않는다. |
| 공통 | 보스 사망 시 필살기는 즉시 종료한다. 기존 `warn → charge → stun`, B04 격노 전환 중에는 필살기를 시작하지 않는다. 필살기는 추가 적·소환을 만들지 않는다. |

바닥 위험 표식은 실제 통과 가능한 바닥에만 놓는다. 벽·고체 장애물·포탈 진입 위치를 막는 곳에는 생성하지 않는다. 모든 필살기 피해는 기존 일반 피격 규칙을 사용하며, 한 시전 안에서 정해진 최대 피해 횟수를 넘겨 적용하지 않는다.

## 1. B02 — `복도 봉쇄선`

**역할:** Stage 2 복도(`halfX 7.5`, `halfZ 19.2`)에서 E04 투사체와 다른, 길이 방향 빈틈 이동을 요구한다. B02의 기존 공통 돌진은 유지한다.

| 항목 | 최종 추천 사양 |
|---|---|
| 발동 조건 | B02 HP가 **70% 이하**가 될 때 1회, **35% 이하**가 될 때 1회. 각 임계치는 독립적이며 재처치·회복·reset으로 재발동하지 않는다. `elapsed >= 200초`이면 미발동 임계치도 시전하지 않는다. |
| 예고 | B02가 **1.2초 정지**한다. 복도 폭 전체를 가로지르는 통제선 3개를 Z축으로 순서가 보이게 표시한다. |
| 실행 | 통제선 3개가 Z축 방향으로 순차 이동·활성화된다. 각 선은 복도 X축 폭 전체를 가로지르므로, 좌우 벽에 붙는 것만으로 피할 수 없다. B02 본체는 시전 중 이동·돌진하지 않는다. |
| 피해 | 활성 통제선 접촉 시 **18 피해**. 한 번의 `복도 봉쇄선`에서는 플레이어가 최대 1회만 피해를 받는다. |
| 회피 | 예고된 선 사이의 빈 구간으로 복도 길이 방향 이동. 선이 켜지는 순서와 이동 방향을 먼저 읽고 다음 빈 구간으로 넘는다. |
| 종료 | 마지막 선이 끝나면 B02는 **1.2초 경직** 후 기존 추적/돌진으로 돌아간다. |
| 금지 | 투사체 0, 소환 0, B02 v2 모델·Studio·저장·legacy 경로 변경 0. |

## 2. B03 — `왕복 오래달리기`

**역할:** 체육관(`halfX 7.5`, `halfZ 19.2`)의 넓은 바닥에서, 체육교사 B03이 정해진 레인을 왕복해 플레이어의 선행 위치 선정을 시험한다. 기존 공통 돌진과 별개다.

| 항목 | 최종 추천 사양 |
|---|---|
| 발동 조건 | B03 HP가 **65% 이하**가 될 때 1회, **30% 이하**가 될 때 1회. 각 임계치는 독립적이며 `elapsed >= 200초`에는 시전하지 않는다. |
| 예고 | 단일 레인을 **1.25초** 표시한다. 표시가 끝난 뒤에는 레인을 바꾸거나 플레이어 위치를 다시 조준하지 않는다. |
| 실행 | B03이 고정된 단일 레인을 왕복 **2회** 달린다. 레인은 체육관 가로 방향이며, 달리는 동안 추가 적을 소환하지 않는다. |
| 피해 | 각 왕복 접촉은 **16 피해**, 한 번의 `왕복 오래달리기` 최대 피해는 **32**다. 같은 왕복에서 중복 피해는 없다. |
| 회피 | 예고된 레인 밖의 반대쪽 공간으로 이동해 레인이 지나간 뒤 복귀한다. 레인이 고정되므로 예고를 보고 먼저 벗어나는 것이 정답이다. |
| 종료 | 두 번째 왕복이 끝나면 B03은 **1.2초 경직** 후 기존 추적/돌진으로 돌아간다. |
| 금지 | 추가 보스 0, 일반 좀비/런크루 소환 0. |

## 3. B04 — `국물 대폭발`

**역할:** B04 주방장의 기존 HP 50% 격노 전환을 한 번의 바닥 회피 패턴으로 확장한다. P1 포격의 투사체 슬롯을 공유하지 않는다.

| 항목 | 최종 추천 사양 |
|---|---|
| 발동 조건 | B04 HP가 **50% 이하가 되는 기존 격노 전환**에서 정확히 1회. `elapsed >= 200초`이면 별도 필살기 시전은 시작하지 않고 기존 P2 전환만 수행한다. |
| 예고 | 통과 가능한 바닥의 서로 겹치지 않는 원 3개를 **1.2초** 표시한다. 고체 조리대·가구·포탈 위치에는 원을 만들지 않는다. |
| 실행 | 예고 뒤 원 3개가 **동시에 폭발**한다. P1 포격용 `enemyProjectilePool`은 사용하지 않는다. |
| 피해 | 한 시전의 플레이어 피해는 최대 **16**이다. 원이 겹치거나 동시에 맞아도 이 상한을 넘기지 않는다. |
| 회피 | 예고 중 세 원 밖의 연결된 통로로 빠져나간다. 원 3개 밖에는 항상 이동 가능한 안전 경로가 남아야 한다. |
| 종료 | 폭발이 끝나면 바로 기존 B04 **P2 격노 돌진**으로 전환한다. |
| 금지 | 투사체 0, 소환 0, 고체 장애물 0. |

## 4. 처치 보상 — 영구 보스 패시브

모든 아이템은 해당 보스를 **처음 처치한 순간** 해금한다. 현재 런에 즉시 한 번 적용되고 이후 새 런에도 유지한다. 같은 보스 재처치·중복 사망 콜백·reload/reset 뒤에도 같은 효과를 다시 곱하거나 더하지 않는다.

| 슬롯 | 보스 | 아이템 | 축 | 정확 효과 | 적용 규칙 | 퀘스트 가방 표시 문구 |
|---:|---|---|---|---|---|---|
| 1 | B01 | 삼각자 | 공격 | 커터칼·30cm 자·바이키티 공격력 ×1.05 | 현행 정본 유지. 대상 세 무기에 1회만 적용. | `삼각자 — 커터칼·30cm 자·바이키티 공격력 +5%` |
| 2 | B02 | 복도 출입증 | 공격 | 연필·벨·오니기리 `damage ×1.05` | `pencilThrow`, `bell`, `onigiri` 세 무기만 대상이며, 무기별 1회만 적용한다. 사거리·관통·쿨다운은 바꾸지 않는다. | `복도 출입증 — 연필·벨·오니기리 공격력 +5%` |
| 3 | B03 | 체육관 호루라기 | 생존 | 최종 이동속도 `×1.05` | 기존 영구 이동속도 및 관리자 밸런스가 계산된 뒤 1회만 적용한다. 기존 속도 상한은 그대로 유지한다. | `체육관 호루라기 — 이동속도 +5%` |
| 4 | B04 | 급식 국자 | 생존 | 최종 최대 체력 `×1.05` | 기존 최대 체력이 계산된 뒤 1회만 적용한다. 런 중 해금이면 현재 HP를 같은 **HP 비율**로 환산한다. | `급식 국자 — 최대 체력 +5%` |
| 5~8 | — | 빈 슬롯 | — | 효과 없음 | 추후 보스 보상 전용. | `빈 보스 패시브 슬롯` |

### 패시브 불변식

1. B01~B04 보상은 서로 함께 적용될 수 있지만, 각 보상은 보스별로 정확히 한 번만 적용한다.
2. B02는 세 지정 무기의 `damage`만 `×1.05`한다. B01과 대상이 겹치지 않는 무기는 그대로다.
3. B03은 최종 속도에 `×1.05`를 한 번만 적용하며, 기존 속도 상한을 우회하거나 바꾸지 않는다.
4. B04는 최종 `maxHp`에 `×1.05`를 한 번만 적용한다. 런 중 해금 시 `hp / maxHp` 비율을 보존해 새 `hp`를 계산한다.
5. 기존 B01과 동일하게 저장 실패가 현재 런의 보스 처치·전투를 막지 않는다.

## 5. 구현 전 acceptance 기준

- B02/B03/B04는 150초 등장, 마틸다는 205초 경고·210초 등장으로 유지된다.
- 세 필살기 모두 `elapsed >= 200초`에는 새 시전을 시작하지 않는다.
- B02는 HP 70%/35%에서 각 1회, B03은 HP 65%/30%에서 각 1회, B04는 HP 50% 격노 전환에서 정확히 1회다.
- B02 시전은 피해 최대 18, B03 시전은 최대 32, B04 시전은 최대 16을 넘지 않는다.
- B02/B04는 투사체·소환을 만들지 않고, B03도 추가소환을 만들지 않는다.
- B02 v2 no-legacy gate를 통과하며 B02 모델·Studio·저장 경로를 바꾸지 않는다.
- 가방은 B01~B04 보상을 슬롯 1~4에 순서대로 표시하고 슬롯 5~8은 비어 있다.
- B02/B03/B04 재처치·중복 콜백·reload/reset 뒤에는 피해·속도·체력이 중첩되지 않는다.
