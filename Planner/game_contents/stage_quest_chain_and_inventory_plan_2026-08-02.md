# 스테이지 연속 퀘스트 8종 및 퀘스트 가방 기획안

- 작성일: 2026-08-02
- 범위: 스테이지 1~4에 각 2개, 총 8개 퀘스트와 퀘스트 아이템 인벤토리
- 상태: 1차 구현 완료(2026-08-02). 상태 로직·월드 상호작용·퀘스트 가방 UI·회귀 테스트·브라우저 확인 완료

## 1. 핵심 결정

1. 각 스테이지에는 퀘스트가 정확히 2개 존재한다.
2. 플레이어가 퀘스트 학생을 조사하면 해당 퀘스트가 시작되고, 그때 월드에 퀘스트 아이템이 등장한다.
3. 두 퀘스트는 순서와 관계없이 동시에 진행할 수 있다.
4. 퀘스트 아이템은 가까이 가면 자동 획득되고 `퀘스트 가방`에 보관된다. 버리기·판매·수동 사용 기능은 만들지 않는다.
5. 아이템을 학생에게 돌려주거나 지정 시설에 설치하면 자동 소비되며 퀘스트가 완료된다.
6. 퀘스트는 스테이지 클리어의 필수 조건이 아니다. 미완료여도 보스, 포탈, 다음 스테이지 해금은 막히지 않는다.
7. 8개 퀘스트는 두 개의 이야기 줄기로 이어지지만, 이전 퀘스트 완료를 다음 퀘스트의 시작 조건으로 삼지 않는다.
8. 아이템과 진행도는 현재 탈출 플레이 전용이다. 새로고침·사망·재시작 시 초기화하고 계정·로컬 저장은 1차 구현 범위에서 제외한다.

## 2. 전체 퀘스트 구조

### 이야기 줄기 A — 친구를 다시 움직이게 하기

`말빨기술책 → 압박붕대 → 주장의 호루라기 → 알레르기 명단`

말을 못 하거나 다친 학생들이 다시 행동할 수 있게 도우면서, 학교 곳곳의 생존자들이 하나의 대피 집단으로 모이는 흐름이다.

### 이야기 줄기 B — 학교 비상체계 복구

`비상 출석부 → 방송실 마스터키 → 전광판 예비 퓨즈 → 가스 밸브 손잡이`

누가 남아 있는지 파악하고, 방송과 안내 시설을 살리고, 마지막에는 급식실의 위험 설비를 차단하는 흐름이다.

두 줄기는 서사만 연속된다. 예를 들어 스테이지 1의 출석부 퀘스트를 놓쳐도 스테이지 2의 방송실 열쇠 퀘스트는 정상적으로 시작된다.

## 3. 공통 플레이 흐름

1. 스테이지 진입 시 두 퀘스트는 `발견 전` 상태다.
2. 퀘스트 학생에게 접근해 조사 대사를 끝까지 확인한다.
3. 수락 버튼 없이 대사 종료와 동시에 퀘스트가 자동 시작된다.
4. 화면에 `새 퀘스트` 토스트가 뜨고, 지정 위치에 아이템이 등장한다.
5. 아이템은 작은 빛기둥과 위아래 부유 애니메이션으로 일반 소품과 구분한다.
6. 아이템 반경 안에 들어오면 자동 획득되며 `가방에 보관했습니다` 토스트가 뜬다.
7. 가방에서 아이템 이름, 용도, 돌려줄 대상 또는 설치 위치를 확인할 수 있다.
8. 학생에게 다시 접근하거나 지정 시설에 접근하면 아이템이 자동 사용되고 완료 대사가 나온다.
9. 보상은 즉시 한 번만 지급한다. 보상 선택 모달은 열지 않는다.

## 4. 스테이지별 상세 퀘스트

### 스테이지 1 — 교실

#### 1-A. 말빨은 책으로 배운다

- 퀘스트 학생: 교실 서쪽에 쓰러져 있지만 의식은 있는 말없는 학생
- 시작 대사: `난 말을 잘 못하거든… '말빨기술책'이 있다면!!!`
- 목표 안내: `교실 반대편에서 말빨기술책을 찾아 학생에게 돌려주자.`
- 퀘스트 아이템: `말빨기술책`
- 아이템 외형: 분홍 표지에 말풍선과 느낌표가 그려진 작은 책
- 등장 위치: 북동쪽 버려진 책상 `stage1-desk-ne-01` 위
- 획득 문구: `말빨기술책을 찾았다. 표지부터 말이 많다.`
- 완료 조건: 책을 가진 채 퀘스트 학생에게 다시 접근
- 완료 대사: `좋아… 이제 말할 수 있어. 다들 내 말 듣고 침착하게 나가자!`
- 보상 초안: 골드 2
- 연출: 완료한 학생 머리 위의 회색 말풍선이 분홍 체크 표식으로 바뀐다.

#### 1-B. 반장의 마지막 출석 확인

- 퀘스트 학생: 교실 남쪽에 있는 반장 학생
- 시작 대사: `누가 교실을 빠져나갔는지 알아야 해… 비상 출석부가 앞쪽 책상에 있을 거야.`
- 목표 안내: `교실 북서쪽 책상에서 비상 출석부를 찾아 반장에게 돌려주자.`
- 퀘스트 아이템: `비상 출석부`
- 아이템 외형: 파란 집게판에 빨간 체크가 표시된 출석부
- 등장 위치: 북서쪽 책상 `stage1-desk-nw-01` 서랍 앞
- 획득 문구: `비상 출석부를 찾았다. 몇몇 이름에는 급하게 동그라미가 쳐져 있다.`
- 완료 조건: 출석부를 가진 채 반장에게 다시 접근
- 완료 대사: `확인했어. 복도로 나간 애들이 있어. 우리도 뒤따라가자.`
- 보상 초안: 골드 2
- 다음 스테이지 연결: 스테이지 2 진입 문구에 `복도에도 아직 학생들이 남아 있다`가 한 줄 추가된다.

### 스테이지 2 — 복도

#### 2-A. 304번 사물함의 압박붕대

- 퀘스트 학생: 복도 북동쪽의 팔을 다친 학생 `stage2-student-east-north`
- 시작 대사: `304번 사물함에 압박붕대가 있어. 비밀번호는 0304… 보안은 원래부터 포기했어.`
- 목표 안내: `복도 사물함에서 압박붕대를 찾아 다친 학생에게 돌려주자.`
- 퀘스트 아이템: `압박붕대`
- 아이템 외형: 흰 붕대 롤과 붉은 고정 클립
- 등장 위치: 유효한 `corridorLockerBank` 중 플레이어에게서 가장 먼 사물함 앞
- 획득 문구: `압박붕대를 찾았다. 포장에는 '체육대회용'이라고 적혀 있다.`
- 완료 조건: 붕대를 가진 채 다친 학생에게 다시 접근
- 완료 대사: `됐다. 이제 혼자서도 움직일 수 있어. 고마워.`
- 보상 초안: 골드 2
- 배치 예외: Firebase 배치 변경으로 사물함이 없으면 청소 카트가 대체 등장 위치가 된다.

#### 2-B. 분실물 게시판 뒤의 마스터키

- 퀘스트 학생: 복도 중앙의 방송부 학생 `stage2-student-west-mid`
- 시작 대사: `비상 방송을 해야 해. 방송실 마스터키를 분실물 게시판 뒤에 붙여 뒀어.`
- 목표 안내: `복도 남쪽 분실물 게시판에서 방송실 마스터키를 찾자.`
- 퀘스트 아이템: `방송실 마스터키`
- 아이템 외형: 노란 열쇠표가 달린 낡은 황동 열쇠
- 등장 위치: `corridorLostFoundBoard`의 게시판 아래
- 획득 문구: `방송실 마스터키를 찾았다. 열쇠표에 '방송실·절대 분실 금지'라고 쓰여 있다.`
- 완료 조건: 열쇠를 가진 채 방송부 학생에게 다시 접근
- 완료 대사: `좋아. 복도 끝까지 대피 방송을 내보낼게. 넌 계속 가!`
- 보상 초안: 골드 2
- 연출: 완료 직후 화면 상단에 짧은 비상방송 자막만 표시하고 전투는 멈추지 않는다.
- 배치 예외: 게시판이 없으면 청소 카트 `corridorJanitorCart`를 대체 위치로 사용한다.

### 스테이지 3 — 체육관

현재 스테이지 3 배치에는 조사 학생이 없으므로 아래 퀘스트 학생 2명을 체육관 가장자리에 새로 배치해야 한다.

#### 3-A. 주장의 호루라기

- 퀘스트 학생: 서쪽 벤치 옆에 다친 농구부 주장
- 시작 대사: `애들이 패닉이야… 내 호루라기만 있으면 한쪽으로 모이게 할 수 있어.`
- 목표 안내: `북동쪽에 흩어진 농구공 사이에서 주장의 호루라기를 찾자.`
- 퀘스트 아이템: `주장의 호루라기`
- 아이템 외형: 빨간 끈이 달린 은색 호루라기
- 등장 위치: 농구공 더미 `stage3-balls-ne-scattered` 옆
- 획득 문구: `주장의 호루라기를 찾았다. 아직도 짧게 삑 소리가 난다.`
- 완료 조건: 호루라기를 가진 채 농구부 주장에게 다시 접근
- 완료 대사: `좋아, 내가 애들을 정리할게. 체육관 출구는 네가 열어 줘!`
- 보상 초안: 골드 2
- 연출: 완료 시 호루라기 시각 효과만 1회 재생하며 적 상태에는 영향을 주지 않는다.

#### 3-B. 꺼진 비상 전광판

- 퀘스트 학생: 동쪽 벽 근처에 있는 체육부 시설 담당 학생
- 시작 대사: `북쪽 전광판을 켜면 비상구 방향을 띄울 수 있어. 예비 퓨즈가 공 보관 카트에 있어.`
- 목표 안내: `공 보관 카트에서 예비 퓨즈를 찾아 북쪽 전광판에 설치하자.`
- 퀘스트 아이템: `전광판 예비 퓨즈`
- 아이템 외형: 투명 케이스 안에 든 주황색 대형 퓨즈
- 등장 위치: 공 카트 `stage3-ball-cart-nw` 아래 선반
- 획득 문구: `예비 퓨즈를 찾았다. '점수판용'이라고 굵게 적혀 있다.`
- 완료 조건: 퓨즈를 가진 채 전광판 `stage3-scoreboard-north-wall`에 접근
- 완료 문구: `전광판이 켜지고 비상구 방향 화살표가 나타났다.`
- 보상 초안: 골드 2
- 연출: 전광판 숫자가 잠시 깜빡인 뒤 `EXIT →`로 바뀐다. 포탈 해금 조건에는 영향을 주지 않는다.

### 스테이지 4 — 급식실

현재 스테이지 4 배치에도 조사 학생이 없으므로 배식대와 벽면 쪽에 퀘스트 학생 2명을 새로 배치해야 한다.

#### 4-A. 배식 전 알레르기 확인

- 퀘스트 학생: 남쪽 배식대 근처의 급식 당번 학생
- 시작 대사: `남은 음식을 나눠 주고 싶은데, 알레르기 있는 애들 명단이 없어. 동쪽 조리대에 있을 거야.`
- 목표 안내: `동쪽 조리대에서 급식 알레르기 명단을 찾아 당번 학생에게 돌려주자.`
- 퀘스트 아이템: `급식 알레르기 명단`
- 아이템 외형: 우유·땅콩·달걀 표식이 붙은 코팅 문서
- 등장 위치: 동쪽 준비대 `stage4-preptable-east-side-counter` 위
- 획득 문구: `알레르기 명단을 찾았다. 얼룩졌지만 이름은 읽을 수 있다.`
- 완료 조건: 명단을 가진 채 급식 당번 학생에게 다시 접근
- 완료 대사: `이제 안전하게 나눠 줄 수 있어. 한 명도 더 아프게 하지 않을게.`
- 보상 초안: 골드 2
- 배치 예외: 해당 준비대가 없으면 가장 가까운 `kitchenPrepTable`을 사용한다.

#### 4-B. 멈추지 않는 가스 밸브

- 퀘스트 학생: 북동쪽 싱크대 근처의 조리부 학생
- 시작 대사: `쿡라인 가스가 새! 빨간 밸브 손잡이가 싱크대 쪽으로 굴러갔어.`
- 목표 안내: `싱크대 근처에서 밸브 손잡이를 찾아 북쪽 쿡라인에 설치하자.`
- 퀘스트 아이템: `가스 밸브 손잡이`
- 아이템 외형: 십자 모양의 빨간 금속 손잡이
- 등장 위치: 북동쪽 싱크대 `stage4-sink-north-east` 앞 바닥
- 획득 문구: `가스 밸브 손잡이를 찾았다. 뜨겁지는 않지만 기름투성이다.`
- 완료 조건: 손잡이를 가진 채 쿡라인 `stage4-cookline-north-center`에 접근
- 완료 문구: `밸브를 잠갔다. 쿡라인의 불꽃과 가스 소리가 잦아든다.`
- 보상 초안: 골드 2
- 연출: 쿡라인의 불꽃·연기만 꺼진다. 기존 전투 난도와 적 스폰에는 영향을 주지 않는다.

## 5. 퀘스트 가방 UI

### 버튼

- 위치: 좌측 상단 일시정지 버튼 바로 오른쪽, 간격 8px
- 크기: 기존 일시정지 버튼과 동일한 44×44px
- 아이콘: 주인공이 메는 형태를 본뜬 `핑크색 란도셀` 정면 그림
- 기본 상태: 칠판색 버튼 + 핑크 란도셀
- 새 퀘스트 아이템 상태: 오른쪽 위에 작은 노란 `!` 배지
- 접근성 이름: 닫힘 `퀘스트 가방 열기`, 열림 `퀘스트 가방 닫기`

현재 `PlayerMesh.jsx`의 가방 소스는 청록 본체·진청 포켓·파란 끈이다. 핑크 아이콘은 이번 요청에 따라 퀘스트 UI의 고유 색상으로 사용한다. 실제 3D 가방까지 핑크로 맞추는 작업은 별도 시각 결정으로 남긴다.

### 열고 닫기

- 플레이 중 버튼을 누르면 기존 `paused` 상태를 재사용하고 `pauseSource: 'quest'`로 가방을 연다. 새로운 게임 phase는 추가하지 않는다.
- 가방은 사용자가 버튼을 눌렀을 때만 열린다. 퀘스트 시작·아이템 획득 시 자동으로 열지 않는다.
- 가방 버튼 재클릭, 닫기 버튼, `Esc`로 닫는다.
- 닫으면 가방을 열기 전 상태로 돌아간다.
- PC는 좌측 사이드 패널, 모바일은 화면 하단 시트로 표시한다.

### 패널 정보 구조

1. 제목: `퀘스트 가방`
2. 요약: `진행 중 2 · 아이템 1`
3. 진행 중 퀘스트 카드 최대 2개
   - 퀘스트 이름
   - 현재 목표 한 줄
   - 상태: `학생에게 돌아가기` 또는 `시설에 설치하기`
   - 보상
4. 퀘스트 아이템 목록
   - 아이콘, 이름, 한 줄 용도, 관련 퀘스트
5. 완료한 퀘스트는 현재 스테이지 안에서 체크 표시로 남기되, 아이템 칸에서는 제거한다.
6. 빈 상태: `아직 받은 퀘스트가 없어요. 도움이 필요한 학생을 조사해 보세요.`

## 6. 상태와 저장 규칙

퀘스트 상태는 아래 여섯 단계만 사용한다.

`undiscovered → active → item-acquired → completed`

예외 종료 시 `missed`, 런 초기화 시 다시 `undiscovered`가 된다.

- 스테이지에는 두 퀘스트 정의가 항상 존재하지만 학생을 조사하기 전에는 가방에 표시하지 않는다.
- 같은 퀘스트 학생, 아이템 또는 설치 지점 이벤트가 중복 호출되어도 진행과 보상은 한 번만 반영한다.
- 인벤토리 칸 수, 무게, 스택, 버리기, 판매는 없다.
- 아이템 획득원은 고유 `sourceId`로 한 번만 소비한다.
- 완료 보상은 `rewardedIds`로 중복 지급을 막는다.
- 스테이지 전환 때 미완료 퀘스트는 `missed`가 되고 보유 아이템은 삭제된다.
- 완료 기록만 현재 4스테이지 탈출 여정의 결과 요약까지 유지한다.
- 사망·새로고침·다시 시작은 현재 여정의 퀘스트 상태를 모두 초기화한다.
- 초기 버전에서는 Firebase와 `localStorage`에 퀘스트 진행을 저장하지 않는다.

## 7. 놓침과 소프트락 방지

- 퀘스트를 받기 전에 아이템 위치를 조사해도 아이템은 소비되지 않는다. 퀘스트 시작 후 정상 등장한다.
- 아이템은 적 공격, 폭발, 물리 충돌로 밀리거나 파괴되지 않는다.
- 아이템 등장 위치가 Firebase 소품 배치 변경으로 사라지면 같은 타입의 다른 소품, 그다음 지정 대체 소품 순으로 배치한다.
- 대체 소품도 없으면 맵 가장자리의 안전한 고정 위치에 생성한다.
- 학생에게 돌려주는 아이템은 별도 `사용` 버튼 없이 접근만으로 완료한다.
- 포탈이 열린 뒤에도 해당 스테이지 안에 있는 동안 퀘스트는 계속 진행할 수 있다.
- 포탈 진입 시 확인 모달로 막지 않는다. HUD에 `미완료 퀘스트가 남아 있습니다`를 한 번만 작게 알린다.
- 퀘스트 보상으로 무기 선택 모달, 필수 회복, 포탈 해금 또는 보스 약화를 제공하지 않는다.

## 8. 보상 기준

- 1차 밸런스 값은 퀘스트당 골드 2, 전체 8개 완료 시 총 16골드로 시작한다.
- 조사 보상과 중첩돼도 퀘스트 완료 보상은 한 번만 지급한다.
- 업그레이드 선택, 영구 능력치, 계정 해금은 포함하지 않는다.
- 실제 플레이에서 동선 부담 대비 보상이 지나치게 작거나 큰지만 짧게 확인한 뒤 조정한다.

## 9. 구현 순서 제안

1. 퀘스트 정의 8개와 순수 상태 전이 로직
2. 퀘스트 학생 조사 → 아이템 스폰 → 획득 → 반납/설치 흐름
3. 스테이지 3·4 퀘스트 학생 배치
4. 핑크 란도셀 버튼과 퀘스트 가방 패널
5. 퀘스트 아이템 8종의 단순 3D 모델과 표시 효과
6. 중복 획득·스테이지 전환·재시작 회귀 테스트

## 10. 완료 기준

- 각 스테이지에 정확히 두 개의 퀘스트가 있고 서로 독립적으로 시작·완료된다.
- 학생 조사 전에는 아이템이 없고, 조사 대사 종료 후 지정 위치에 등장한다.
- 아이템 획득 즉시 가방에서 확인할 수 있다.
- 반납형 6개와 설치형 2개가 각각 정상 완료된다.
- 같은 이벤트가 반복돼도 아이템과 골드는 한 번만 지급된다.
- 미완료 상태에서도 기존 보스·포탈·클리어 흐름이 유지된다.
- 가방 버튼은 일시정지 버튼 옆에 있고 PC·모바일에서 최소 44px 터치 영역을 가진다.
- 가방을 열면 게임이 기존 일시정지 체계로 멈추며, 닫으면 정상 재개된다.
- 스테이지 전환 시 미완료 아이템이 다음 스테이지로 새지 않는다.
- 새로고침·재시작 후 이전 아이템이나 완료 보상이 중복 복원되지 않는다.
