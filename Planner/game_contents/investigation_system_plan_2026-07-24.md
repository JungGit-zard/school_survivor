# 물건·사람 조사 시스템 기획안

작성일: 2026-07-24

## 1. 핵심 목표

맵에 놓인 사람과 물건을 단순 배경이 아니라 플레이어가 직접 확인할 수 있는 탐색 요소로 만든다. 조사는 위험한 이동 중 잠시 경로를 바꾸게 하고, 운이 좋으면 생존에 도움이 되는 보너스를 얻는 선택지가 된다.

## 2. 공통 규칙

- 조사 대상 가까이에 접근하면 조사가 시작된다.
- 각 대상은 한 번의 플레이에서 1회만 조사할 수 있다.
- 보너스가 나오지 않아도 대상별 짧은 대사나 설명을 표시해 세계관 정보를 전달한다.
- 조사창이 열린 동안 게임을 일시정지하고, 창을 닫으면 다시 진행한다.

| 조사 대상 | 총 보상 확률 | 당첨 보상 |
|---|---:|---|
| 사물함 (`locker`) | 100% | 업그레이드 선택 기회 1회 |
| 쓰러진 학생 (`student`) | 50% | 업그레이드 선택 기회 1회 50% / 골드 10개 50% |
| 불레틴보드 등 기타 대상 | 10% | 기존 보상 풀: 업그레이드 선택 기회 1회 50% / 골드 10개 50% |

## 3. 현재 적용 대상

| 스테이지 | 대상 | 조사 표시 |
|---|---|---|
| 전체 해당 배치 | 쓰러진 학생 | 학생의 무작위 대사 |
| 스테이지 2 | 사물함 | 내부를 확인했다는 조사문 |
| 스테이지 2 | 불레틴보드 | 게시물과 단서를 확인했다는 조사문 |

사물함과 불레틴보드는 벽과 충돌체에 붙어 있으므로 학생보다 넓은 조사 접근 범위를 사용한다. 화면상 멀리 떨어진 상태에서 발동하지 않고, 충돌체 바로 앞까지 접근했을 때만 작동해야 한다.

현재 조사 가능한 사물함은 스테이지 2 배치에만 있다. 스테이지 1에는 학생 조사 대상만 유지하며, 이 보상 정책 변경으로 사물함을 새로 배치하거나 이동하지 않는다.

## 4. 특별 보너스 확장안

조사를 중요한 성장 요소로 확장할 때는 모든 보너스를 한꺼번에 추가하지 않고 스테이지별 보너스 풀로 관리한다.

- 회복형: 체력 소량 회복, 일시 보호막
- 전투형: 제한 시간 공격력·공격 속도 증가
- 탐색형: 주변 경험치·골드 끌어오기, 숨은 조사 대상 표시
- 정보형: 보스 약점 또는 다음 이벤트 위치 힌트
- 수집형: 조사 전용 기록, 학생 명단, 학교 비밀 문서

사물함·학생·기타 대상의 총 보상 확률은 위 표를 정본으로 관리한다. 대상별 보상 풀이 확장되어도 현재 사물함의 100% 업그레이드와 학생의 50% 총 확률·50:50 보상 비중은 유지한다.

## 5. 밸런스·악용 방지

- 한 판에서 같은 대상을 반복 조사해 보상을 재추첨할 수 없다.
- 조사 완료 여부는 새 판을 시작할 때만 초기화한다.
- 메뉴 일시정지 중에는 새 조사가 발동하지 않는다.
- 보상 지급은 조사창을 정상적으로 닫을 때 한 번만 실행한다.
- 영구 저장이 필요한 보상은 기존 Firebase 진행 저장 흐름만 사용하며 브라우저 로컬 저장소를 사용하지 않는다.

## 6. 향후 단계

1. 조사 가능 대상에 가까워졌을 때 작은 공통 아이콘을 표시한다.
2. 자동 조사와 버튼 조사 중 플레이 감각이 더 좋은 방식을 모바일에서 비교한다.
3. 대상별 전용 보너스 풀과 희귀도 UI를 추가한다.
4. 조사 기록 도감을 Firebase 계정 진행도에 연결한다.
5. 스테이지별 조사 목표와 숨은 이야기 묶음을 설계한다.

## 7. 완료 기준

- 스테이지 2의 사물함과 불레틴보드가 학생과 같은 조사 흐름으로 작동한다.
- 각 대상은 한 판당 1회만 조사된다.
- 사물함은 항상 업그레이드 선택 기회를 제공하고, 학생은 50% 총 보상 확률을 유지하며, 기타 대상은 10% 총 보상 확률을 유지한다.
- 보상 없음, 골드, 업그레이드 세 경로가 게임 진행을 정상 재개한다.
- 조사 시스템 확장 시 대상 정보만 추가하고 공통 판정·보상 코드를 재사용할 수 있다.
