# 전기충격기 2차·3차 strict chain 규칙 (2026-07-26)

- 2차와 3차는 각각 직전 타격 좀비의 그 순간 위치를 중심으로 다시 검색한다.
- hit history는 `rb` 객체만이 아니라 `{ rb, generation }` 쌍으로 기록한다.
- 풀 슬롯이 재사용되어 같은 `rb`가 새 generation을 얻으면, 새 좀비는 이미 맞은 좀비가 아니며 거리 후보에 포함한다.
- 이동 그래픽과 실제 `applyEnemyHit`는 선택 시점의 같은 `{ rb, generation }`을 사용한다.
- 이전 착탄 좌표, 플레이어 좌표, 재사용 전 generation은 후속 체인 대상 선택에 사용하지 않는다.
- 체인 수, 4.5 범위, 피해, 쿨다운, 속도는 변경하지 않는다.
