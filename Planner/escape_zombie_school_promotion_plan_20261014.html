1 게임 소개와 약속 범위

탈출! 좀비학교는 학교에서 몰려오는 좀비를 피하며 자동 공격과 레벨업 카드로 성장하고 탈출을 노리는 생존 액션 게임이다. 연필·자·텀블러 같은 생활용품이 무기가 되고, 친구를 돕는 퀘스트와 동료가 학교라는 배경에 의미를 더한다. 공포만 강조하기보다 익숙한 학용품의 엉뚱함과 아슬아슬한 회피 장면을 보여 준다.

항목홍보에 쓸 표현구분할 사항
가격무료, 게임 내 광고와 유료 구매 없음유료 홍보비와 게임 안의 결제는 별개다. BM은 수익을 내는 구조를 뜻하며 이 계획에는 새 BM을 넣지 않는다.
웹설치 없이 브라우저에서 플레이시작 전 Google 로그인이 필요하다. “무가입”, “로그인 없이 즉시 플레이”라고 쓰지 않는다.
조작이동하면서 피하고 공격은 자동, 레벨업 때 카드 선택모바일 조작·기기별 성능은 실제 대상 기기의 확인 범위로 안내한다.
학교교실·복도·체육관·급식실에서 생존과 탈출세부 수치·등장 시각은 배포 상태 확인 없이 약속하지 않는다.
성장이번 판의 카드 선택, 플레이로 얻는 골드와 성장현금 결제나 광고 시청을 성장 조건으로 표현하지 않는다.
첫 도전먼저 60초 생존에 도전해 주세요60초 전용 모드, 60초 클리어 보상, 새 이벤트를 만든 것이 아니다.

게스트 진입이나 타이틀 개선은 별도 제안으로만 남긴다. 이 홍보안을 이유로 로그인·타이틀·게임·Firebase 데이터를 변경하지 않는다. 기존 전체 게임 가이드에 남은 게스트 설명보다 현재 확인된 로그인 필요 조건을 따른다.

웹 플레이는 https://escapezombie.com/game를 기본 목적지로 사용한다. 공식 첫 화면과 소개 페이지는 설명이 필요할 때 보조 링크로 쓴다. Android 링크는 프로젝트 기존 문서의 Google Play 등록 주소를 사용한다. 공개 배포 트랙과 이용 가능 국가 확인 전 “누구나 설치 가능”이라고 단정하지 않는다.

2 대상 플레이어와 메시지

4 게시처 주소와 현행 규칙

확인일은 2026년 10월 14일이다. “확인됨”은 공개 규칙을 읽었다는 뜻이며 해당 계정의 게시 승인이나 게임의 진입 성공까지 보장하지 않는다. 게시 직전 고정 공지를 다시 읽고 현재 계정의 자격을 확인한다.

게시처와 정확한 주소확인된 규칙실행 판단
디시 인디 게임 개발 갤러리2026년 10월 6일 최신 공지는 홍보·테스트 성격의 글에 일지탭 글 5개 이상을 전제로 한다. 홍보탭이 HIT탭과 통합되었다고 안내한다.기존 계정의 개발일지 5개 충족 확인 전 홍보글 보류. 갯수를 채우려는 빈 글 도배 대신 실제 개발 과정만 기록한다.
네이버 인디게임개발자쉼터 인디터카페 본문 접근 오류로 최신 게시판·등급·홍보 간격은 미확인이다.로그인한 계정으로 공지와 게임홍보 또는 테스트 게시판을 확인하거나 운영진에게 문의한 뒤 결정한다. 자동 게시 대상이 아니다.
r/playmygame공식 규칙 JSON에서 무료로 지금 플레이 가능, 직접 게임 링크, 설명과 본인의 개발 참여, 사실에 맞는 설명, 동일 게임 1개월 재게시 간격을 확인했다. NDA 게임은 금지이며 공포 성격은 NSFW 표기 규칙이 있다.Google 로그인 필수 사실을 밝힌다. JSON에는 계정 요구의 허용 여부가 명시되지 않아 현행 고정글·작성 양식과 운영진 판단을 추가 확인한다. 당장 게시 가능으로 단정하지 않는다.
국내 웹게임 게시처 검토 예시 겜마니오락실신규 개발자 게임 접수 창구·규칙을 확보하지 못했다.게시 가능한 곳으로 간주하지 않는다. 담당자의 접수 안내가 확인될 때만 제휴 후보로 검토한다. 초기 실행 채널에서 제외한다.

국내 개발갤은 오래된 공지의 “홍보 말머리”만 보고 게시하면 최신 규칙과 어긋난다. 2026년 10월 6일 공지의 일지 5개 조건을 먼저 적용하고 기본 규칙도 함께 확인한다. Reddit 기준은 공식 규칙 JSON을 근거로 한다.

커뮤니티별 허용 시간이나 횟수를 추측해서 만들지 않는다. 확인이 끝나면 채널 기록에 계정, 게시판, 읽은 공지 URL, 확인 시각, 다음 게시 가능일을 적는다. 삭제된 글을 곧바로 재게시하거나 추천·조회수를 구매하지 않는다.

5 기존 블로그 자산과 검색 유입

10 채널별 링크와 UTM 사용

UTM은 링크 끝에 붙이는 유입 이름표다. 사용자의 게임 값을 바꾸는 기능이 아니며 링크를 만들었다고 분석 데이터가 자동으로 검증되는 것도 아니다. /game을 직접 목적지로 잡아 소개 페이지에서 한 번 더 눌러야 하는 단계를 줄인다.

파라미터쉬운 뜻예시

utm_medium어떤 방식의 유입인가blog, social, community, referral
utm_campaign어떤 모집 활동인가playtest_202610
utm_content어떤 글이나 영상인가pencil_60s_ko, card_choice_en

같은 글의 링크 이름은 게시 후 바꾸지 않는다. source는 소문자 영문으로 통일하고 이름·이메일·UID·토큰을 넣지 않는다. Short의 공용 프로필 링크는 여러 영상이 함께 쓰므로 그 링크만으로 특정 영상의 성과를 정확히 나눌 수 없다. 영상별 클릭을 분리할 수 없으면 채널 단위 성과로 적는다.

분모가 0이면 0% 대신 “계산 불가”라고 적는다. 식별 기준이 없거나 수집이 누락되면 “미측정”으로 적고 추측으로 채우지 않는다. Firebase 랭킹 기록 수를 전체 방문자수로 사용하지 않는다.

측정 준비와 확인 순서

  1. 현재 이벤트 정의를 읽어 방문·로그인 시도·성공·실제 판 시작·게임시간 60초·판 종료를 어떤 이벤트와 조건으로 볼지 대응표를 만든다. app_open, login_state, level_start, run_checkpoint, level_end 같은 이름만으로 의미가 충족됐다고 판단하지 않는다.
  2. 태그와 이벤트의 실제 네트워크 송신, GA 실시간 또는 DebugView 수집, UTM source·campaign을 확인한다. DebugView는 시험 이벤트를 실시간으로 보는 화면이다. 게임 체크포인트가 정확히 60초인지 별도 확인한다.
  3. 실제 대상 환경의 새 세션에서 로그인과 핵심 진입이 끝까지 되는지 검증한다. 현재 문서 작성 단계에서는 실행하지 않았으며, 실제 Firebase 값을 건드리는 테스트라면 프로젝트의 초기 스냅샷·완전 복원 규칙을 먼저 충족한다.
  4. 필요한 이벤트가 없으면 계측 작업을 별도 요청으로 분리한다. 인증 토큰·이메일·개인정보를 이벤트에 넣지 않고, 동의와 개인정보 고지를 확인한다. 관측이 불가능한 재방문은 수동 자발적 피드백과 구분한다.

14 결과에 따른 결정과 유료 홍보 조건

관찰먼저 할 일
조회수는 있지만 클릭이 적다첫 장면·CTA·프로필 링크를 확인한다. 게임 코드를 바꾸지 않는다.
방문은 있지만 로그인 성공이 적다실제 로그인 실패와 로그인 요구를 보고 이탈한 경우를 구분한다. 인증 변경은 별도 작업과 실제 대상 환경 검증을 거친다.
로그인은 되지만 판 시작이 적다시작 단계·로딩·에러를 기록한다. 라이브 서비스를 중단하지 않는다.
판은 시작하지만 60초 전 많이 끝난다조작 이해·체력 감소·끊김·선택 혼란을 묻는다. 난이도를 임의 수정하지 않는다.
60초까지 오지만 다시 하지 않는다첫 판 재미와 두 번째 판에서 기대하는 선택을 묻는다.
결과가 대부분 미측정이다조회수만으로 채널 승자를 정하지 않는다. 측정 준비와 자발적 피드백을 우선한다.

유료 홍보는 사용자 승인과 예산이 필요한 선택지다. 지금 집행액은 이 작업 기준 0원이며, 무료 홍보가 실제 시작을 만든 소재와 정확한 측정이 확보된 뒤에만 검토한다. YouTube Promote 또는 소규모 크리에이터 협업 중 하나를 후보로 두고 대상·기간·총 청구 상한·세금·중단 조건을 승인받는다. 두 가지를 동시에 시작하지 않는다.

기존 2026년 10월 3일 계획의 하루 실제 청구 10,000원 이하 한도는 예산 비교 참고이며 새 집행 승인이 아니다. 평균 일예산과 실제 하루 청구 상한은 다를 수 있으므로 계정의 결제·세금·지출 규칙을 확인한다. 60초 도달자가 0이면 관련 비용 지표를 계산 불가로 적고 확대하지 않는다. 유료 사용자를 데려오는 비용은 광고비 ÷ 실제 신규 판 시작자, 광고비 ÷ 60초 도달 신규 이용자로 따로 계산한다. 게임에 광고나 유료 구매를 추가하는 제안은 포함하지 않는다.

15 게시 점검과 출처

게시 직전에 다음을 확인한다.

  • 무료와 게임 내 광고·유료 구매 없음, 시작 전 Google 로그인 필요가 함께 적혀 있다.
  • 60초를 별도 모드·클리어 시간·보상으로 약속하지 않는다.
  • 보여 주는 플레이 장면은 실제 게임이며 콘셉트 이미지에는 구분 표기가 있다.
  • 현재 미배포 랭킹 요청과 미검증 계측을 제공 완료로 쓰지 않는다.
  • 채널 공지와 게시 자격을 충족하고 UTM과 목적지 링크가 맞다.
  • 실제 게시 URL·시각을 남긴다. 버튼 클릭 기록과 공개 게시 확인은 구분한다.
  • 기존 예약·타이틀·로그인·게임·Firebase 정본을 이 홍보안만으로 변경하지 않는다.
