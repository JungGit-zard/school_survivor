## 적용 범위

신규 좀비 상세안은 **급식 배식원**을 우선 후보로, **식판 운반원·국자 투척수·청소 당번**을 선택 후보로 다룬다. 각 안에는 실루엣·부품·크기 후보·준비/공격/회복 동작·대응법·등장 구간·기존 적 대체 방식·구현 접점·개별 수용 기준이 있다. 추가 적을 한꺼번에 투입하는 계획이 아니다.

그래픽 문서는 팔레트 HEX·재질·바닥/동선·장애물·압력솥/보스 경고·모바일 가독성·Studio 연결·필요 자산까지, 종합 문서는 퀘스트·보상·영구 진행·우선순위·검증 시나리오까지 다룬다.

이 묶음은 고도화 **제안서**다. 게임 코드·모델·자산·Firebase 값 변경이나 운영 배포를 뜻하지 않는다. 제안 수치는 사용자 확정값을 대체하지 않는다.

기존 구현과 개선 제안은 각 문서에서 구분한다. 현재 화면을 직접 관측하지 않은 내용은 확인할 위험 또는 제안으로 취급한다. 과거 구현 추출본과 로컬 소스, 원격 추적 참조는 서로 다른 시점일 수 있으며 어느 것도 실제 운영 상태·Firebase 실효값의 검증을 대신하지 않는다.

진행 조건의 기준은 사용자 지시다. 4스테이지는 3스테이지 보스 처치로, 5스테이지는 4스테이지 보스 처치로 즉시 영구 해금한다. 탈출·생존시간·퀘스트는 추가 해금 조건이 아니다. 현재 구현 일치 여부는 기획서의 근거와 후속 검증 항목을 참조한다.
