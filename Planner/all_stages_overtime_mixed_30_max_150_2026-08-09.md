# 전 스테이지 5:00 이후 혼합 일반 좀비 반복 보강 (30마리 요청, 동시 150 상한)

작성일: 2026-08-09
담당: Level_Mini

## 목표
- Stage 1~4에서 플레이 시간이 정확히 300초(5분 00초)에 도달하면 첫 추가 보강을 요청한다.
- 이후 30초 간격(330초, 360초, 390초, ...)으로 플레이 중인 동안 같은 보강을 반복 요청한다.
- 각 보강은 일반 좀비 30마리를 요청하되, 현재 생존/대기 중인 좀비 총량이 150마리를 넘지 않도록 남은 슬롯까지만 생성한다.

## 규칙
1. 스폰 시각
   - 시작: 300초 = 5분 00초.
   - 반복 간격: 30초 = 0분 30초.
   - 틱 계산은 `floor((elapsedSec - 300) / 30)` 기준으로 결정해 프레임 스킵 시에도 현재 틱 1회만 발화한다.
   - stage/gameKey 리셋 시 마지막 발화 틱은 -1로 초기화한다.
2. 수량
   - 보강 1회 요청 수량: 30마리.
   - 전역 동시 좀비 상한: 150마리.
   - 상한 계산에는 pooled active, special boss/Matilda active, deferred pooled spawn queue를 모두 포함한다.
   - 남은 슬롯이 0이면 새 보강은 건너뛰며 기존 좀비는 삭제하지 않는다.
3. 타입 풀
   - Stage 1: `E01,E02,E03,E05,E06,E07`만 사용한다. Stage 1 no-E04 규칙을 유지한다.
   - Stage 2~4: `E01,E02,E03,E04,E05,E06,E07`을 사용한다.
   - 보스, RZ 이벤트 적, 마틸다, 도지는 포함하지 않는다.
4. 스폰 방식
   - 기존 Enemies 스폰 위치 함수, stage HP override, pooled spawn drain queue를 사용한다.
   - 기존 웨이브, 110초 보강, 보스, 마틸다, 도지, 스탯/모델/AI는 보존한다.

## 거리/블록 단위
- 이번 변경은 시간·수량 규칙이며 신규 거리값은 추가하지 않는다.
- 기존 스폰 위치/반경 규칙은 현재 코드값을 그대로 사용한다.

## 수용 기준
- 299.999초에는 발화하지 않고, 300초에 tick 0, 330초에 tick 1, 360초에 tick 2가 된다.
- 동일 tick 안에서는 중복 발화하지 않고, 프레임 스킵으로 360초에 처음 도달해도 현재 tick 2를 1회만 발화한다.
- Stage 1 보강 30개 샘플에는 E04가 없고 E07을 지원한다.
- Stage 2~4 보강 풀은 E01~E07을 모두 지원한다.
- 동시 좀비 총량이 149마리면 최대 1마리만 추가되고, 150마리면 0마리 추가된다.
- `MAX_ENEMIES`와 `MAX_CONCURRENT_ZOMBIES`는 150이다.
